# HUD 字号下限标准（GAMES-57 · VIS 波基准）

> 状态：**生效**（2026-09-27，GAMES-57 单链 #9 落地） ｜ 适用：全目录（单机 GE 壳 + 联机壳），
> 供后续 VIS 波全量引用。事实源：本文件；违反即识图 v2 复检不过。

## 0. 背景

mosaic-03 识图 OCR 误读暴露：375×667 逻辑分辨率下 **11px 非加粗数字**在 DSF=1 截图中
已低于 OCR 可靠识别阈值（笔画粘连、数位互吞）。HUD 数字是玩家的战术决策输入（资源/
兵力/倒计时/比分），误读成本远高于装饰文本；同时 OCR 识图是本平台质量门禁的一环
（quality-pipeline §8.4），字号下限因此是**平台级标准**而非单作偏好。

口径说明：本标准中的 px 均指**逻辑画布坐标系**（375×667 portrait 基准）。真机 CSS 缩放
（`scale = min(vw/375, vh/667)`）不改变逻辑字号；识图截图 DSF=1 时逻辑 px 即截图 px。

## 1. 分级与下限

| 级 | 定义 | 下限 | 字重 | 例 |
|---|---|---|---|---|
| **P0 数字/读数** | 玩家战术决策依据的数字，需 1s 扫读 | **≥13px** | ≥600 | HP、积分、兵力、倒计时、CP、能量、ping、关卡号、通关进度、结算战报数字 |
| **P1 交互标签** | 按钮/卡面/技能名等可点元素文本 | **≥11px** | 400-700 | 出兵卡名+造价、技能名+能耗、研究钮、结算按钮 |
| **P2 辅助标注** | 装饰/提示/版权，误读无决策成本 | **≥9px** | 400 | 克制角标、T 阶徽记、塔名、页脚 slug·version |

裁量记录：
- **ping 归 P2（11px）**：网络状态徽标，非战术决策数字（玩家不据它做操作），且 60px
  顶栏三行布局中行 3 仅 11px 净空。若后续单作把 ping 提升为战术信息（如延迟补偿提示），
  升 P0 处理。
- **OCR 特征位**（识图协议锚点文本，如本作"6 宫格出兵卡+双色积分条"）至少 P1 且关键
  数字 P0——识图素材必须可机读。
- **13px 从何而来**：OCR 实测 11px/400 字重数字误读率高；13px/600 在 PingFang SC 下数字
  笔画x高约 9-10 逻辑 px，DSF=1 截图 OCR 误读率归零（GAMES-57 识图复检实证）。

## 3. 阵营色盲双编码校验表（双色+形状双通道）

平台阵营双色 A 琥珀 `#E8A33D` / B 青 `#3DC8E8` 的色觉安全分析（CIE 模拟）：

| 色觉 | A 琥珀感知 | B 青感知 | 色相可辨 | 依赖形状通道 |
|---|---|---|---|---|
| 正常三色 | 琥珀 | 青 | ✓ | —（冗余） |
| 红绿色盲 protan/deutan | 黄褐 | 蓝 | ✓（蓝-黄轴安全） | 冗余 |
| 蓝黄色盲 tritan（罕见） | 粉褐 | 青绿 | **✗ 风险** | **必需** |

结论：蓝黄轴双色调对最常见色盲安全，但 tritan 下失效——**形状编码为强制第二通道**。
本作落地（GAMES-57）：

| 元素 | 色相通道 | 形状通道 |
|---|---|---|
| 占点旗帜（稳态+翻转动画） | 阵营色 | **A 三角旗 / B 燕尾旗**（右缘内凹） |
| 顶栏/战场基地血条 | 阵营色 | **A 实心 / B 分段**（12px 周期 9 实 3 隙） |
| 单位底盘阴影 | 阵营色本体 | **A 椭圆 / B 方形** |
| 双向积分条 | 阵营色 | 方向（A 左半向中 / B 右半向中）+ 中缝白线锚点 |
| 基地带 | 阵营色 | 位置（A 底缘 / B 顶缘）+ 裂纹档位 |
| 己方单位 | — | 白圈描边（seat 判据，色盲无关） |

复核方法：识图 v2 截图（home/play/late 三时刻）灰度化后逐元素核对形状差异可辨
（REPORT 附截图）；新增 VIS 波沿用本表口径。
