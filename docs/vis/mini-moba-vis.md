## 0. 本单发现：HF 非法简写=全 HUD 10px 缺省字（P0 级修复）

GAMES-127 落地的 `HF(tag, px, weight)` 构造 `13px 700px -apple-system,…`——size
前置于 weight 且 weight 带 `px` 单位，**非法 CSS font 简写，canvas 赋值被静默忽略**
（实测回读恒 `10px sans-serif`）。全 HUD 实际以 10px 缺省字渲染；QA1（GAMES-128）
的 HF 登记 {p0:13,…} 与识图核验双双放行——登记表只记**调用值**不记**生效值**，
10px 数字恰在 OCR 可读边缘未暴露。

修复与防回归（口径已固化进断言工具）：

| 项 | 修复 | 断言 |
|---|---|---|
| 简写合法性 | `weight + ' ' + px + 'px family'`（tactics-duel GAMES-124 同式） | V-HUD-1b 静态 + V-HUD-3 `__applied` 往返自证 |
| 生效自证 | `hudFonts()` 附 `__applied`：HF 串赋 ctx.font 后回读含 `13px` | V-HUD-3（旧实现此处恒 false） |
| 分级下限 | `__cls`：HF_CLS 按 P0/P1/P2 记 min/samples | V-HUD-2（P0≥13/P1≥11/P2≥9 运行样本） |
| 字号归位 | 伤害/金币飘字 12→**13/700 P0**（dmgF 新键）；buyP 12→13 | V-HUD-2 + V-BR-2 |

`hudFonts()` 保持平铺 `{tag:px}` 兼容 GAMES-131 feel-check（FE-1f/FE-4c：`__cls`/`__applied`
为非数值新增键，不进共同键比对；** caveat：goldF/dmgF 等键值变化=旧基线重放会红，须重采 base**）。

## 3. 观战导演 UI（QA1 观察项兑现，协议面零改动）

- **入口**：`?spectate=1&room=<id>` → join mode:'spectate'（rooms.js 既有分支，
  GAMES-132 满员兜底旁观之外的显式观战入口；协议无新消息）。
- **自动热点追踪**：客户端镜头跟随快照 `ext.aoi`（服务端 `__dirCam`=kill/tower/
  shrine 8s 事件质心，0.2 收敛已由 sim 提供）以 0.08 缓推；近 6s 有击杀/推塔/圣所
  事件 → 导演条「⚔ 交战热点」红字脉冲。
- **跟焦点切换**：导演条「◀ 上一/下一 ▶」钮或**任意触点点屏**（观战位无摇杆/技能
  钮）在 AOI 内存活英雄间轮换；焦点出圈/阵亡自动回退自动模式；焦点席 KDA 行金框
  高亮+小地图白环。
- **KDA 面板**：底栏 A/B 两列×3 席——英雄字形+职业名+L 等级（AOI 内可见时）+
  K/D/A（**客户端簿记** kill 事件 killer/victim/assists，观战收全事件流为
  GAMES-128 §S5 已证）。团队击杀/存塔分沿用顶栏 ext.t。
- **观战位语义**：seat=-1（`drawControls` 让位 `drawSpecUI`；F11 草丛/F15 消失
  警示/输入环 10Hz 上报全部跳过）；结算页胜方中性呈现（「B 方胜利」阵营色）。
- **小地图导演信息**：视野圈中心=ext.aoi；主视口白框=镜头位置；兵线灰点=迷雾内
  兵线动向。
