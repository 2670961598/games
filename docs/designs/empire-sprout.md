## 1. 玩法循环

**定位**：玩家同时执掌"城"（领地实时成长——S2 状态同步）与"军"（军团帧同步对局——S1 帧同步）两个节奏盘，双表盘一世界：种田练兵是慢钟，军团交锋是快钟，**建设层决定你能出什么兵，战斗层决定这些兵打成什么样**（创意库 T3-A/T3-B 主轴）。双人 2v2（席位不足 Bot 补位），S3 混合同步承载（roadmap 技术矩阵 S3 首证）。竖屏 375×667。

### 1.1 对局时间轴（8-12 分钟，tick=100ms，maxTicks=7200）

```
tick 0 ────── 1800 ──────────────── ~3600-6600 ──────── 7200
  │  建设期 3min  │      军团战期 5-9min      │  超时硬顶  │
  │  和平发展      │  爆发→2-4 波军团攻防      │  终局裁定  │
  爆发帧=1800（固定）：军团战解锁、首张战斗帧下发、号角演出
```

- **建设期（tick 0-1799）**：战斗通道静默（§5.1），无战事无消耗——纯发展：铺经济、升兵营、练兵蓄池。
- **爆发帧（tick 1800）**：服务器合成首张战斗帧（events `[{k:'erupt'}]`），march 解锁，客户端强制切战场表盘+全屏号角 banner。
- **军团战期**：两钟并行（S3 核心体验）：前线军团交战的同时，后方继续建造/升营/练兵——第二波永远比第一波强。
- **终局**：`eliminated`（敌方城心摧毁，常态 tick 3600-6600）或 `timeout`（7200 比城心 HP% → 战功 → draw）。

### 1.2 三循环（产出 → 练兵 → 出征）

| 循环 | 机制 | 数值 |
|---|---|---|
| 产出 | 三资源自动累积（被动+建筑）；资源**每席独立**，城心/城墙**全队共享** | 被动 粮 3/木 2/铁 1 每秒；建筑产出见 §2.2 |
| 建造 | 己方 4 建筑位造/升 6 种建筑（同类每席至多 1 座）；兵营种类决定可练兵种池 | 造价见 §2.2；瞬时落地（无工期），钱到即成 |
| 练兵 | 兵营排队练兵（队列串行 ≤5/营，多营并行）；完成入**兵池**（上限 12/席） | 造价/时长见 §2.3；兵营 Lv=可练档位（T1/T2/T3 数值表） |
| 出征 | 从兵池编成**军团**（attack op，单次 ≤12）整队开赴战场车道；**出征 CD 20s/席** | 军团同帧成组入场（§5.3 编队表）；阵亡释放后可再练再出 |

### 1.3 胜负条件（先到者胜）

1. **摧毁**：敌方**城心** HP 归零（城墙 800 HP 是城心前最后防线，横跨三车道共享一条）→ reason=`eliminated`。
2. **超时**：maxTicks=7200（12 分钟）→ 比城心 HP 百分比高者胜，平则比**战功**（击杀 +2/个、破墙 +40、城心命中 +1，战斗层累计），再平 `draw` → reason=`timeout`。
3. abandon（全员离线 15s）沿用协议。

预期对局长 8-12 分钟：空城流（不练兵）被首波推平 ~tick 3400（A3 剧本）；均势拉锯 2-4 波军团 ~tick 5000-6600；经济碾压流（T3 兵营+heavy）后程终结；timeout 兜底 12 分钟。

### 1.4 单拇指操作映射（375×667 安全区，右手拇指全程可达）

**领地表盘（默认）——点选为主**：

| 手势 | 指令 | 反馈 |
|---|---|---|
| **点**（建筑位，≥44×44px 热区） | `build`：空位弹建造面板（6 种建筑卡+造价/产出预览）；已建弹升级面板（Lv+1 造价） | 蓝图呼吸光；确认即尘土+光柱（升级 Lv3 金光），资源飘字 −N |
| **点**（兵营） | `train`：练兵面板（池内兵种卡+数量步进 1-5） | 入队即时，队列进度条（§3.2）；完成单位"踢正步"入池 |
| **点**（兵池徽标） | `attack`：出征面板（编队构成步进+车道三分选）→ 确认出征 | 扣池即时+号角+军团从城门涌出（CD 环 20s） |
| **点**（底栏〔军〕切换钮）｜双指捏合（辅助） | 切战场表盘（250ms 转盘翻转） | 爆发帧自动强制切换 |

**战场表盘——指挥官战场式车道指挥**：

| 手势 | 指令 | 反馈 |
|---|---|---|
| **长按**（战场车道 ≥400ms） | `rally`：设该车道集结线（slg 同款；再长按拖动可改，点城心图标重置） | 长按视觉脉冲+集结旗标记（阵营色形状双编码） |
| **点**（快出条） | `attack`：一键复用上次编队+当前兵池（不足按比例裁） | 同领地出征反馈 |
| **点**（〔城〕切换钮） | 回领地表盘（建设中/练兵中角标呼吸提醒） | 转盘翻转回 |

单拇指原则：建设=全 tap 大热区（面板按钮 ≥44×44px）；战斗=车道三分区大目标（无精确定位——200ms 延迟下不惩罚瞄准，§5.6）。**双指捏合是快捷方式而非必经**（创意库 T3-A 的"双指捏合"调整为"切换钮为主、捏合为辅"——单拇指铁律优先，见 §8）。

### 2.5 数值校核（供平衡讨论留档）

**(a) 开局产能线（建设期 180s，单席）**：被动 木 2/s → t≈15s 建伐木场（木 30）→ t≈35s 农田（木 40）→ t≈55s 步兵营（木 60 铁 40，铁被动 1/s 已攒 55）→ 粮收入 3+4=7/s，t=55-180s 采粮 ~875+缓冲 ≈ **10×inf T1**（粮 1000）。军备线（mine@90s + works@120s）：铁 1+2=3/s 起 → 180s 时 **2-4×razor + 4×inf**——首发更少但质高（razor 180 HP vs inf 60）。双席合计开局军团 16-24 单位。

**(b) 拆家线**：8×inf T1 对墙 DPS = 8×(10×1.25)=100 → 墙 800 HP ≈ 8s、城心 1200 ≈ 12s（无减员理想值；实战对轰减员拉长 2-3 倍）；T3 heavy 单体对建筑 DPS=104 ≈ 8 只 inf——攻城特化成立（一只顶一队，但粮 1050/铁 440/练 12s 的账单也一只顶一队）。

**(c) 全局节奏**：首波接团 tick ~1860-2000（两军中场相遇）→ 首破墙 tick ~2600-3600 → 终局 tick 3600-6600（6-11 分钟），timeout 7200 兜底 → **8-12 分钟包络成立**。

**(d) 克制三角**：inf→arty→razor→inf 保留（slg 校核结论"无废兵"沿用）；sniper=侧位克制（vs inf 1.75、被 razor 近身碾压）；heavy=攻城特化（对兵 DPS/造价低、对建筑 ×2）——六兵无废位。

**(e) 资源三池分工**：粮=兵员（唯一练兵货币）、木=城建、铁=机械兵+高阶建筑——三池互不替代，建设取舍真实（饿死的军团 vs 没铁的 T3 营）。

### 3.2 建设 juice 清单

建筑完工：尘土粒子 300ms + 顶起弹跳；升级完工：光柱 400ms（Lv3 金色）+ 等级徽记弹跳。练兵完成：单位从营门"踢正步"走出并入兵池徽标（徽标 +N 跳动，P0 数字 13px 基准 +2.2）。出征：号角音效 + 城门开合 200ms + 军团涌出（前 200ms 尺度 0.6→1.0）+ 车道高亮。资源飘字 −N 滚动。**爆发演出**（tick 1800）：全屏战鼓 banner"军团战爆发"+ 强制切战场表盘（转盘翻转 250ms）+ 双方城墙落地尘暴。

### 3.3 战斗 juice 清单（slg §3.3 基底 + 攻城件）

命中火花/阵亡碎裂粒子（阵营色）/击杀战功飘字 +2/连歼横幅（同队 5s 内 3+ 击杀）；**城墙受击**：裂纹三档贴图（75%/50%/25%）+ 破墙瞬间全屏震屏 ±5px 衰减 400ms + 石屑粒子雨；**城心受击**：防守方全屏边缘红/青脉冲；**城心摧毁**：慢动作 0.5×（渲染层 timeScale）2s + 大爆炸 + 震屏 ±6px 500ms。音效锚点：建造（锤夯）/完工（号角短音）/出征（战鼓）/破墙（石裂闷响）/终局（凯旋|覆灭）。

## 4. Bot 三档策略（建设倾向 × 战斗时机双轴差异化）

Bot 走网关 Bot 宿主统一接口（`spawnBot('empire-sprout', level)`）。**单 brain 双通道输出**：建设 op（build/train/attack）走与真人相同的 input 消息 `keys.o` 壳（服务器权威应用）；战斗 cmd（rally）走 `keys.c` 壳入战斗输入帧——与真人的通道逐字节同路径。三档参数表（可执行，DEV 抄进 sim 文件头；绝对 tick 为"顺序与风格"非字面，brain 以资源就绪门控实现——slg 接线先例）：

| 参数 | casual 慢发展 | balanced 均衡 | competitive 军备竞速 |
|---|---|---|---|
| 决策间隔 | 50 tick | 20 tick | 10 tick |
| 建设倾向（固定 build order 即人格主轴） | 农本：lumber→farm→farm Lv2→camp（军事最后） | 均衡：lumber→farm→camp→mine→works；tick~1500 camp Lv2 | 军备：lumber→camp→farm→works；camp Lv2 @~1200、**Lv3 @~2400（前线打着后方升营——S3 并行秀）** |
| 练兵 | inf 连练（池 6 止步） | 池内混编 inf:razor 2:1 | **情报克制**：读敌方最近军团构成（建设快照可读，服务器侧合法）→ 练克制兵；无情报 inf:heavy 2:1 |
| 出征时机 | 爆发后池 ≥6 且 CD 好（首征常 tick 2100+，慢半拍） | 池 ≥8 即征 | **timing attack**：tick 1800 CD 即满池压上；此后 CD 好且池 ≥10 |
| 车道选择 | 固定 lane 1 | 敌方最薄车道（slg F2 同款计数法） | 双线分压（lane 0/2 交替）+ 破墙后集火 lane 1 |
| rally | 无 | 前线 1/2 深度 | 动态随战团；破墙后 rally 压敌城心行 |
| 危机反应 | 被破墙后 30% 概率补征 | 被破墙即满池再征 | 被破墙即征 + 补建 mine 采铁转 heavy |
| 升级经济建筑 | 仅经济线到 Lv2 | 营 Lv2 后回补经济 Lv2 | 不回补（军事滚雪球，赌前线终结） |

难度曲线意图：casual 给新手"能推平"的正反馈（纯 inf 慢半拍，A2 剧本）；balanced 陪玩主力（混编有来有回）；competitive 提供速通压力（tick 1800 即满池 timing attack + 情报克制，A3 剧本）。真人加入让位/断线托管沿用协议 §2（逾时转 casual 托管，brain 双通道整体接管）。

## 5. S3 混合同步协议细节（核心节）

本节在 net-protocol v1.1 冻结框架内落 empire-sprout 的分层实现细则；消息复用 §4.1/§4.2 既有类型 + §6 **S3 预留扩展位 `frame.ext.layer:'build'|'battle'` 分层标记**（快照侧同式 `snapshot.ext.layer:'build'`），零协议变更、无需变更单（mmo/slg 游戏级声明先例）。**分层协议文档化**（roadmap §2 S3 行深度要求）即本节。

### 5.1 双通道与单一时钟

- **单一 tick 源**：网关一个 100ms 定频循环驱动两层——tick N 同时是建设层快照序与战斗层帧号（同一全局时钟，无相位漂移、无两套对时）。
- **建设通道（S2）**：每 tick 一张快照（10Hz）`{t:'snapshot', frame:<全局tick>, base, snapSeq, full, ext:{layer:'build'}, ents:[…], events:[…]}`——mmo 二式快照范式照搬（全量/增量、snapSeq 缺口检测、300 张周期全量）。
- **战斗通道（S1）**：`{t:'frame', frame:<全局tick>, inputs:{<seat>:{cmd:{…}}}, events:[…], ext:{layer:'battle'}}`——slg 离散 cmd 帧范式照搬。
- **静默期**：tick < 1800 战斗通道**不下发**（无战斗帧字节）；tick 1800 = 首张战斗帧（服务器合成，inputs 全 noop、events `[{k:'erupt'}]`），客户端战斗 sim 从冻结初始态（空单位+墙/心满血）启动。此后逐帧推进至终局。战斗帧号沿用全局 tick（首帧 frame=1800）——回放日志 `{seed, tickMs, inputs[frame]}` 中 frame < 1800 恒为 noop。
- **AOI 不需要**：单屏领地全量状态小（4 席 × ≤4 建筑 + 队列 + 三资源 + 兵池 + 2 队墙/心镜像 ≈ 全量 1.5KB、增量常态 <400B）——roadmap S2 行的 AOI 简化版在单屏场景退化为全量下发，**按连接不裁剪**（敌盟领地数据也全量下发：Bot 情报克制与 api-check 需要读；客户端呈现层只画己盟——迷雾是呈现层取舍而非保密需求，休闲 SLG 无排位无作弊威胁面，见附决策 8）。

### 5.2 建设层快照细则（S2）

- **二式快照**：全量（join/reconnect/sync/每 300 张校准）`ents` 携带全部建设实体；增量 `ents` 只含本 tick 脏实体（资源数每 tick 恒脏但可 1s 粒度化——资源数整秒快照下发，省 90% 增量字节）、`events` 携带表现事件。**增量阈值**：脏实体 >16 或增量字节 >全量 ×0.7 → 本张退化全量（mmo 先例）。
- **快照实体**：每席 `{seat, res:{g,w,i}, plots:[{plot,kind,lv}], queues:[{kind,unit,remain}], pool:{inf:n,…}, marchCd}`；每队 `{team, wall:{hp}, keep:{hp}, merit}`——**墙/心/战功为战斗层权威的只读镜像投影**（快照携带投影值使重连一次性恢复双层 UI，§5.4）。
- **events**：`{k:'built',seat,plot,kind,lv}` / `{k:'train-q',seat,kind,unit,n}` / `{k:'train-done',seat,unit}` / `{k:'march',seat,lane,units}` / `{k:'reject',seat,op,why}`（资源不足/池满/CD 中/和平期出征——HUD 抖动红闪的断言源）/ `{k:'cd',seat,remain}`。
- **tick 内结算序**（S2 无确定性义务，语义稳定即可）：`ops 应用（build/train/attack 校验，reject 走 events）→ 资源产出 → 训练队列推进（完成入池）→ attack 结算（扣池/CD）→ 桥投喂（§5.4）→ 快照组包`。

### 5.3 战斗层帧细则（S1）

- **输入上行**：`input = {t:'input', frame:F+1, keys:{ o?:{…建设op…}, c?:{…战斗cmd…} }}`——**双键壳**（游戏级 keys 壳先例扩展）：`o` = 建设 op（服务器权威、下一建设 tick 应用，frame 字段对其无效）；`c` = 战斗 cmd（入 F+1 帧输入日志）。每席位每帧至多 1 条 c（无指令发 `{k:'noop'}`；未收到沿上帧=等价 noop，slg 宽限先例）。
- **战斗 cmd 集**：`{k:'rally', lane:0|1|2, row:0..19}` + `{k:'attack', lane, units:{…}}`（**桥注入专用**，真人不出现在 c 壳——真人的 attack 走 o 壳经建设层校验后由网关合成，§5.4）+ `{k:'noop'}`。全整数/枚举，无浮点无字符串解析歧义。
- **军团入场编队**（确定性编队表）：attack cmd 携带 units 字典 → sim 按**兵种代码字母序**（arty→heavy→inf→medic→razor→sniper）展开，每 3 单位一行向己方纵深排布（A 自 row 17 向 15、B 自 row 2 向 4，milli-px 固定表）——同帧成组入场，无逐个滴流。
- **建筑实体**：墙/城心 = 固定 id 实体（id 1=A 墙、2=A 心、3=B 墙、4=B 心），无移动无攻击；索敌 `dist2 = (Δlane*125_000)² + (Δy)²`（slg 同式，imul 中间量），墙/心按 id 参与受击候选（单位推进至其行射程内自然命中）。
- **确定性纪律（红线）**：slg §5.2 八条全套继承——全整数 milli-px/imul/Q8.8 定点乘子/全序 tie-break `(dist2, entityId)`/AOE 按 id 升序结算/sim 零随机（seed 按 fnv1a32(roomId) 计算随 welcome 下发但判定路径不消耗）/serialize 键字母序。**tick 内结算序**（固定）：`attack 入场（含桥注入）→ 移动 → 医疗光环 → 普攻/AOE（攻击者 id 升序）→ 战功结算 → 胜负判定`（较 slg 去掉 research/占点/能量——本作战斗层无技能无占点）。
- **frame.events**：`{k:'erupt'}` / `{k:'spawn',seat,unit,lane,row}` / `{k:'die',seat,by,unit}` / `{k:'hit',seat,by,dmg}`（聚合） / `{k:'rally',seat,lane,row}` / `{k:'wallhp',team,hp}` / `{k:'keephp',team,hp}` / `{k:'walldown',team}` / `{k:'keepdown',team}`。

### 5.4 跨层一致性边界（S3 核心）

**状态归属表（唯一权威写者）**：

| 状态 | 权威层 | 另一侧角色 |
|---|---|---|
| 资源/建筑/队列/兵池/CD | 建设层（S2 快照） | 战斗层不感知（消耗在建设层扣） |
| 战场单位/墙/城心 HP/战功/胜负 | 战斗层（S1 帧） | 建设层快照携带**只读镜像投影**（UI 血条） |
| 军团构成 | 边界对象：建设层产出（练兵）→ attack 时移交战斗层 | 桥是唯一移交路径 |

**三条单向规则**：

1. **march 桥（建设→战斗，玩家可见路径）**：真人 `attack` op 走 o 壳 → 建设层 tick T 结算（池够/CD 好/已爆发，否则 reject event）→ 网关将该军团合成为该席位的 `{k:'attack', lane, units}` cmd **写入战斗帧 T+1 的输入集**——与真人直接发帧逐字节同形，入输入日志、参与 lockstep、参与确定性回放（回放=纯输入序列重放，桥时序已固化在日志内）。**时序承诺：建设 tick T 结算的出征必出现在战斗帧 T+1**（两层同 tick 源，无相位运气）。
2. **只读投影（战斗→建设，无写路径）**：墙/心/战功经战斗层 events 与快照投影下发；建设层 HUD 只读显示。**建设层永远不写战斗层状态、战斗层永远不写建设层状态**（v1 唯一例外即桥——它是"事件投喂"而非状态改写）。
3. **终局权威**：战斗层 tick 末判定（keep ≤0 或 tick=7200）→ 网关 finish → `end` 消息（协议 §4.2）→ phase ended；建设层无终局判定权。

**预留接口（创意库 T3-C 联盟互助，搁置条目留位）**：盟友资源援助 `aid` op 预留 o 壳第 4 键（`{k:'aid',res,n,to:盟席}`，走建设层结算，零跨层）；战斗层冻结桥预留第二字段 `towerStats`（箭楼类建筑若随 #11 弹性单引入，在爆发帧从城建快照冻结入战斗初始态，此后城建改动不回写战斗）。两者均 v1 不实现、协议位已留。

### 5.5 断线重连（双层恢复）

- 协议 §2 的 10s+1 拍窗不变：`join resume{seat,token}` → `welcome`（含**双层合一 state**：`{build:{…}, battle:{…}}`）→ 建设层直接续流快照（S2 无追帧负担，恢复 <1s）；战斗层 rAF 追帧至当前（每 rAF 至多 4 tick，slg 同款），恢复实时。
- 逾时席位转 bot 托管（casual 档 brain 双通道整体接管——建设继续练兵、战斗继续出征）；`$sync`/`sync` 纠偏同 welcome 全量路径。
- 关键帧快照：服务端每 30 tick serialize 战斗层全量 state（fnv1a32 校验 hash）环形 20 份（覆盖 60s）+ 输入日志自最近关键帧起全保留（slg 同款）；建设层 state 小，welcome/state 直发全量不snapshot-log。

### 5.6 定帧、延迟与带宽预算

- **input delay=1 + 40ms 宽限**（协议 §5 原样）：战斗期客户端收帧 F 即报 F+1（c 壳 noop 或 rally；建设期无战斗帧，input 事件驱动 + ping/pong 心跳）。
- **200ms 模拟延迟可玩性论证**：建设=乐观 UI（≤16ms）+ 快照权威校准（mmo 同款）；战斗=离散指令（attack/rally）+ 本地乐观软状态，权威确认 ≤3 tick——宏观 RTS 节奏无逐帧走位判定（slg 同款论证）。测试口径：A4 双通道注入→反映 <100ms + QA 二号 tc 200ms 模拟延迟试玩。
- **带宽预算/端**：常态 = 建设增量 ~0.4KB×10Hz（资源整秒化后更低）+ 战斗 noop 帧 ~60B×10Hz ≈ **~5KB/s**；交战峰（40 单位互殴 + 事件聚合）~2KB/帧 ≈ 峰值 <25KB/s——与 S1/S2 单层游戏同级（GAMES-53 §4 基线 5.1KB/s@1×），4 连接房网关侧 <100KB/s，轻。

## 附：设计决策记录（REPORT 引用）

1. **双表盘一世界时钟**——建设层与战斗层共享网关同一 100ms 定频（tick N = 快照序 = 帧号），双通道并行下发（协议 §6 预留 `ext.layer` 落地）。两套对时/相位切换是 S3 最大复杂度源，单一时钟从根上消解；静默期（tick<1800）停发战斗帧省 1800 帧 noop 字节，爆发帧=首张战斗帧（inputs 全 noop + erupt 事件）。
2. **attack 桥=唯一玩家可见跨层路径**（单据指定边界）——出征在建设层结算（经济校验的权威场所），网关把军团合成 cmd 写入战斗帧 T+1 输入集：与真人直接发帧逐字节同形，入输入日志、lockstep 与确定性回放零特例。时序承诺"建设 tick T → 战斗帧 T+1"由单一时钟保证，无相位运气。
3. **状态归属单向化**——资源/建筑/兵池权威=建设层，战场单位/墙/心/战功/胜负权威=战斗层；反向只有只读投影（快照带镜像值供 UI 与重连一次性恢复），无任何反向写路径。跨层耦合面收窄到"一个事件投喂"，S3 的确定性纪律因此与纯 S1 等强。
4. **兵营即兵种池（T3-B）+ 6 建筑 4 槽位**——建设决定军事的直接机制化；6 选 4 的放弃感 + 双席分工（经济位/军事位）是 2v2 协作的主要设计空间。
5. **固定爆发帧 1800（非触发式）**——"双方就绪即开战"的触发式爆发需要跨席位握手状态机且节奏不可预期；固定帧给 Bot 剧本、api-check 断言、QA 时间轴全部以确定性锚点，3 分钟建设期也锚定对局下限。
6. **战斗指令面收窄为 attack+rally（技能留弹性位）**——与 slg-battlefield 的差异化即"预备役经济 vs CP 即时流"：本作深度压在建设取舍与波次时机，战场指令保持车道指挥最小面；技能/箭楼/天赋（V1-S1-02/08 同族）全部留单链 #11+，协议位已留（§5.4）。
7. **军团同帧成组入场 + 出征 CD 20s**——军团感（整队开拔）与防滴流节流在同一机制里；兵池上限 12 前移了 slg 的 pop 语义（D6），战场无独立上限而自然上界与 slg 全场 48 单位同级，sim 负载不增。
8. **敌盟领地全量下发、呈现层只画己盟**——单屏状态小（全量 1.5KB）按连接不裁剪；"迷雾"是呈现取舍而非保密需求：Bot 情报克制与 api-check 需要读全量，休闲匿名制下无排位无作弊威胁面（L-11 否决先例）。DEV 实现注意：客户端渲染过滤按 team 字段，勿在协议层裁。
