## 1. 玩法循环

**定位**：3v3 轻量 MOBA（可 Bot 补位）——单主道推塔 + 双侧野区轻量 + 河道圣所团战；一局 8-12 分钟；竖屏 375×667，虚拟摇杆 + 技能钮。S2 状态同步承载（T2 轨道第二款）：服务器权威 10Hz 快照 + 客户端插值 + AOI 视野下发 + 本地移动预测（mmo 范式复用）。**战场节奏（推塔/团战）× 小镇同步管线（快照/AOI/预测）的组合**是本作的工程命题。

### 1.1 对局时间轴（8-12 分钟，tick=100ms，maxTicks=7200）

```
tick 0 ── 150 ────── 2400 ───────────── ~3900-6300 ────── 7200
  │ 选英雄·出门 │ 兵线开波 │ 河道圣所首刷   │  推塔→高地→水晶  │ 超时硬顶
  │ 泉水集结 5s │ 对线期   │ 团战节拍器启动 │  终局窗          │ 终局裁定
```

- **开局（tick 0-149）**：3 席各选 1 英雄（4 位内不可重复，同队；15s 不选=推荐位自动锁定）→ 泉水集结。
- **对线期（tick 150-2399）**：兵线每 30s 一波，补刀/换血/打野/游走 gank（草丛+野区视野盲区）。
- **圣所期（tick 2400 起）**：河道圣所首刷巨灵龟——击杀得全队祝祷（对建筑伤害 +25%/60s）＝**团战节拍器**（固定 2400 首刷给 Bot 剧本与 QA 时间轴确定性锚，empire 固定爆发帧 1800 先例）；此后击杀后 180s 重刷。
- **终局窗**：预期水晶告破 tick 3900-6300（6.5-10.5 分钟，见 §2.8 校核）；timeout 7200 兜底。
- **复活缺席窗**：复活 5+2×等级 秒（L1=7s…L9=23s）+ 归线 ~4.7s——一次击杀=15-28s 的推塔决策窗，后期一次团灭=终局。

### 1.2 单道 vs 三路：选择论证

| 候选 | 论证 | 结论 |
|---|---|---|
| 经典三路 | 竖屏 375px 宽容不下三路信息密度（小地图/兵线三态/野区四象限同屏不可读）；3v3 分三路=每路 1 人，无团战可言；8-12 分钟装不下三路发育节奏 | ✗ |
| 纯单道无野区 | 竖屏可读、最简；但 6 人挤一道=混战坨，无策略纵深、无 gank、游走位无内容 | ✗ |
| **单主道 + 双侧野区支路** | 兵线/推塔只在主道（roadmap §3 T2 行"3v3 单道"合规，竖屏单列可读）；野区=营地资源+草丛视野盲区（gank 深度）；河道圣所=固定团战焦点。等效"1+2 路"：**推塔是单线程的，接近目标的路径是多线程的** | ✓（本设计采用） |

地图结构见 §2.1（世界 1000×1700，主道居中，左右野区各一条纵向支路，河道横贯中场）。

### 1.3 三循环（对线发育 → 资源争夺 → 推塔团战）

| 循环 | 机制 | 数值锚 |
|---|---|---|
| 对线发育 | 补刀拿金（最后一下）、兵线 XP 范围共享、换血（敌方小兵转火=换血成本）、等级自动成长 | 兵金 30/38；XP 34/46；共享半径 260px（§2.6） |
| 资源争夺 | 野区 8 营地（小/灵纹两档）+ 河道圣所；草丛隐身（AOI 之外还有草丛过滤，§5.2）= gank 与反 gank | 灵纹：AD+20 & 技伤+10%/45s；祝祷：对建筑 +25%/60s |
| 推塔团战 | 塔无敌链（T1→T2→水晶）；塔 aggro 转火规则制造越塔强杀决策；圣所祝祷开推塔窗 | 塔金全队 125/150；复活缺席窗 15-28s |

### 1.4 胜负条件（先到者胜）

1. **水晶告破**：敌方水晶 HP 归零（需先破其高地塔 T2 解除水晶无敌）→ reason=`core-down`。
2. **超时**：maxTicks=7200（12 分钟）→ 依次比 水晶 HP% → 存塔数（T1=1 分/T2=2 分）→ 团队击杀数 → `draw` → reason=`timeout`。
3. abandon（全员离线 15s）沿用协议 §2。投降不做（轻量化，v1 无排位无惩罚面）。

### 1.5 等级/装备/复活 轻量化（三刀）

- **等级**：L1-L9 自动成长（XP 到点即升级；无技能加点——技能数值=基础值+英雄等级×成长，单公式）。每级 HP +80~110 / AD +5~7（按英雄表 §2.2）。
- **装备**：全 6 件一次性购买（每件限 1），仅泉水可买（死亡/回城/在泉水）；一键"推荐购买"按英雄路线自动购下一件（§2.7）。无合成树、无主动装备。
- **复活**：`5+2×等级` 秒，泉水满血复活；无死亡金损失、无 buff 转移（死亡清自身灵纹）。
- 附加轻量刀：**无蓝条**（技能纯 CD——少一个 HUD 元素与资源管理面，深度让位给 CD 与装备路线）；**无护甲/法穿**（坦度=HP 与护盾，装备面因此只剩 6 件正交件）；**兵线数值恒定**（无时间成长——杠杆全在英雄等级/装备/团战，校核简单、Bot 可玩）。

### 1.6 操作映射（375×667 安全区，词表 §5.4）

| 手势 | 指令 | 反馈 |
|---|---|---|
| **拖**（左半屏任意处起手浮动摇杆） | `move`：虚拟摇杆（死区 8px，mmo 同款），角色即时跟向（本地预测 §5.5） | 摇杆底盘+帽跟随；移动足迹微尘 |
| **点**（普攻大钮 Ø64px） | `attack`：攻击仲裁最优目标（优先英雄）；长按 0.3s=锁定当前目标不改判 | 目标红圈+攻击动作即时起 |
| **点**（技能钮 ×3，Ø56px） | `skill`：单位目标技自动锁仲裁目标；方向技朝摇杆方向（无摇杆输入=朝最近敌）；区域技以仲裁目标为中心 | 前摇进度弧（§3.3）+ 冷却径向环 |
| **长按**（回城小钮 4s） | `recall`：引导 4s（受击/移动打断）回泉水 | 引导读条+光柱 |
| **点**（泉水内/死亡时商店钮） | `buy`：购推荐下一件（或展开 6 件网格） | 金币飘字 −N + 装备落格 |
| **长按**（小地图 ≥350ms） | `ping`：3 预制轮盘（进攻/撤退/集火，V1-S1-07 采纳位） | 世界标记+队友屏幕高亮；Bot 队友响应（§4.3） |

单拇指可达：摇杆左半屏、技能钮右侧弧排——**双手持机双拇指**是 MOBA 品类基线（与单拇指游戏的差异点，评审已按品类惯例豁免单拇指铁律；摇杆死区/热区参数仍守竖屏规范）。**目标锁定制+方向自动仲裁——200ms 延迟下不惩罚瞄准**（§5.5 论证）。

### 2.8 数值校核（供平衡讨论留档）

- **(a) 兵线均衡**：对称镜像+最近索敌 → 两波中场相遇；单波互殴 DPS ~81 vs 波总 HP 1250 → 一波战 15-18s、波距 30s → 场上同时存活 ≤8 兵（AOI 预算依据，§5.2）。
- **(b) 推塔线**：无守备时塔 DPS 190 清波 ~8-10s、每波仍磨塔 ~650 → 4 波（2 分钟）破 T1；**有守备**（英雄+塔清波 4-5s）每波磨塔 ~300 → 守方在场塔基本不失。预期：首塔 tick 2400-3900（击退/击杀守线者或祝祷窗）、高地 tick 3300-5100、水晶 tick 3900-6300 → **8-12 分钟包络成立**；timeout 7200 兜底。
- **(c) 击杀与 TTK**：L1 对拼全技能 ~120-260 伤害（guard 122 / mage 174 / shadow 258）vs HP 900-1350 → 单次换血 12-25%（早期克制感）；L5 全技能连招 ~500-640（输出位）vs HP 1260-1800 → 对拼 TTK 8-12s（全交+走位拉扯）；塔下强杀：塔 190/1s → 前排顶 6-7s 的越塔窗。复活缺席窗 15-28s（§1.1）与推塔节奏咬合。
- **(d) 经济**：8 分钟人均 ≈ 被动 720+补刀 800-1200+营地/击杀 400-800 ≈ **2000-2700 金 → 2-3 件装备**；6 件天花板不可达（有意：局末仍留成长余量，弹性单可调被动金速率）。
- **(e) 等级分化**：独享一线 148 XP/波 → ~5 分钟 L9（10.4 波 ×30s+取整判级）；三人共享 49 XP/波+营地 → 局末 L7-8；打野游走位靠营地/击杀 XP 补——单线快、共享稳、游走赌，三种站位策略成立。

### 3.1 输入 → 表现延迟预算（红线：LAN 常态 <100ms）

| 摇杆→移动起步（本地） | **≤16ms（1 帧）** | drag 即本地预测移动（§5.5），不等服务器 |

### 3.2 摇杆与移动

- 浮动摇杆任意处起手（左半屏），死区 **8px**（mmo 同款）、最大半径 64px、方向 360° 连续；输出量化 `mx/my ∈ [-100,100]` 整数（协议既有量化）。
- **速度即时映射**（无加速度/减速度）——MOBA 走位即答性：松杆即停（速度归零当 tick 生效）；`速度 = hero.speed × mx/100`（milli-px 整数积分，mmo 同式）。受减速/加速 buff 时对基准速度乘 Q8.8 系数。
- 定身/眩晕期间本地预测冻结（权威 `cc` 状态到场上快速滑移对齐，§5.5）。

### 3.3 技能前摇/后摇与取消（输出技巧层）

- **前摇**（0-250ms，按 §2.2 表）：进度弧显示；**新的移动输入取消施法**（前摇期可反悔=走位秀）；受眩晕打断。
- **后摇** 200ms（收招硬直）：可被移动/下一技能**取消**——取消后摇=高手输出技巧（competitive Bot 显式建模，§4.3）。
- **公共 CD** 150ms（两技能之间的最小间隔），防连点双发。
- 引导（回城 4s）：受击/移动打断，进度条红闪中断。

### 3.4 打击反馈（<100ms 红线的三通道）

- **受击方**：闪白 80ms + 渲染层抖动 2px×3 帧（不入位置状态——服务器权威坐标不动）+ 血条白闪。
- **攻击方**：命中音（物理=锐响/法术=闷响）+ 伤害飘字（§7 双编码）+ 攻击命中停顿（hit-pause）渲染层 40ms。
- **弹道**：轨迹事件驱动（§5.3），600px/s 飞行 300-500ms——命中前的飞行时间=天然的延迟掩体与走位反制窗。
- **击杀**：全屏暗角 200ms + 击杀者慢放 0.3×（渲染层 timeScale）300ms + 播报条（§7）；连杀徽章弹出。
- **塔破**：震屏 ±5px 衰减 400ms + 碎石粒子雨 + 全队播报；**水晶破**：慢放 0.5× 2s + 大爆炸 + 终局结算。

### 3.5 死亡/复活演出

- 死亡：角色碎裂（阵营色粒子）+ 遗留墓碑标记 + 镜头灰度；**死亡视角可拖动观战队友**（AOI 以镜头点为准，与观战同管线，§5.4）。
- 复活倒计时：屏幕中央大数字（P0）+ 泉水方向箭头；复活瞬间泉水光柱 300ms。

## 4. Bot 三档策略（行为优先级仲裁——MOBA Bot 新领域）

Bot 走网关 BotHost 统一接口 `spawnBot('mini-moba', level)`，输出走与真人相同的 input 通道（`keys:{mx,my}` 连续移动 + `cmd` 壳离散技能/攻击/回城/买装——mmo cmd 壳先例）。**MOBA Bot 的特有难点**：同一时刻有"打谁/去哪/何时撤/何时回家"多线程竞争——本作方案=**优先级行为栈仲裁器**（非状态机独占：每拍全栈评估，首个激活行为胜出；MOBA 无先例，本节即仲裁方案冻结）。

### 4.1 仲裁器结构（可执行）

```
每档有决策间隔（casual 10 / balanced 6 / competitive 4 tick）→ 一次仲裁拍：
1. 自上而下扫描行为栈 P0..P8（下表），逐项算「激活分」（0=不激活）
2. 首个激活分>0 的行为胜出 → 生成本拍输出（mx,my 向量 + 至多 1 条 cmd）
3. 滞回：非紧急位（P0/P1 之外）换行为需新行为连续 2 拍分更高——防抖（站桩不抽搐）
4. 连招执行态（P1）内建序列表：按英雄连招表逐条出（等前摇/后摇取消），序列完/目标丢失则退出
```

**行为栈（优先级自上而下）**：

| 位 | 行为 | 激活条件（评分>0） | 输出 |
|---|---|---|---|
| P0 | 生存撤退 | HP%<阈值，或受攻击且近敌数≥近友数+1 且不在己方塔 210px 内 | 向己方最近塔/泉水移动；wind/charge 类位移留逃生 |
| P1 | 连招执行 | 已锁定英雄目标在射程（连招表首技可用） | 按英雄连招序列出技能+普攻+后摇取消 |
| P2 | 集火目标 | 团战态（300px 内 ≥3 英雄交战）或收到集火 ping | 攻击仲裁目标（目标选择见表下） |
| P3 | 补刀 | 敌兵 HP ≤ 普攻预期伤害×窗口系数 | 普攻该兵 |
| P4 | 推线/守线 | 兵线在己方半场（守）或己方优势（推） | 站兵线后 30px 攻击最近敌兵；线过半且无守备→攻击塔 |
| P5 | 换血 | 敌英雄在射程且时机分≥阈值（HP 差+技能 CD+兵转火成本） | 骚扰一套（单技+1-2 普攻）即拉回 |
| P6 | 资源 | 空闲且 400px 内营地已刷（灵纹>小营） | 移动→攻击营地怪 |
| P7 | 游走支援 | 兵线在敌半场（安全）且（圣所 30s 内刷 或 队友 300px 内交战 或 收到进攻 ping） | 移动支援/圣所集合 |
| P8 | 回城补给 | HP<35% 或（金够推荐下一件 且 兵线在敌半场） | 回城引导→买装→返回线 |

**目标选择（P2 仲裁目标，三档分化位）**：casual=最近英雄 ｜ balanced=HP 最低英雄 ｜ competitive=**有效 HP 最低**（HP÷(1+近期受伤)）×威胁权重（对位经济/等级最高者优先=打 carry）+集火 ping 覆盖 5s。

**英雄连招表（competitive 的 P1 序列）**：guard `charge→bash→普攻×2→撤` ｜ ranger `保持 140-160px 间距→pierce→普攻×2→wind 拉开` ｜ mage `star 套位移路（预测 400ms 走位）→frost 定身→普攻→撤` ｜ shadow `blink→venom→普攻→execute（HP<35%）`。

### 4.3 让位、托管与陪玩

- **真人让位**：协议 §2 原样（满员 bot 房真人加入 → seat 最大 bot 席让位，继承等级/装备/位置）。

## 5. S2 协议细节（核心节）

本节在 net-protocol v1.1 冻结框架内落 mini-moba 实现细则；消息复用 §6 已实证扩展位（`t:'snapshot'` 二式 + `snapshot.ext.aoi` + `snapshot.ext.ack`），**零协议变更、无需变更单**（mmo 游戏级声明先例）。**S2/S5 边界：实时战斗走 S2 状态、死亡/击杀走裁决**（§5.3 论证）。

### 5.1 快照通道（10Hz 二式，mmo 范式复用）

- 定频 `tickMs=100` 每 tick 一张快照；sim 只在服务端跑（客户端零判定）。
- **二式快照**：全量（join/reconnect/sync/每 300 张校准）`{t:'snapshot',frame,base,full:1,snapSeq,ext:{aoi,ack},ents:[…静态建筑+AOI 内动态实体]}`；增量 `full:0` 只带脏实体+`leave:[id]`+`events:[…]`。**增量阈值**：脏实体 >24 或增量字节 >全量 ×0.7 → 本张退化全量（团战最坏情形 10Hz 全量仍在预算内，mmo 先例）。
- **实体字段**：hero `{id,seat,hero,x,y,dir,hp,lv,cd:[s1,s2,s3],dead,respAt,buffs,gold,items}`（gold 整秒粒度化省字节，empire 资源整秒化先例）；creep/camp 怪 `{id,kind,x,y,hp,aggro}`；静态：塔/水晶 `{id,team,tier,hp,invuln}`、营地槽 `{id,camp,respawnAt}`、草丛/泉水（join 一次+事件）。
- **events（表现性冗余+裁决账本，§5.3）**：`{k:'shot',by,skill,from,dir,speed,maxDist}`（弹道轨迹）/`{k:'hit',by,vic,dmg}`（聚合）/`{k:'kill',…}`/`{k:'tower',…}`/`{k:'core',…}`/`{k:'camp',…}`/`{k:'buff',…}`/`{k:'recall',seat,phase}`/`{k:'buy',seat,item}`/`{k:'ping',seat,mark,x,y}`/`{k:'reject',seat,op,why}`（非法 cmd 回流——HUD 红闪断言源）。
- **输入上行**：`input={t:'input',frame:<输入序号 seq>,keys:{mx,my,cmd?}}`（S2 语义=seq，mmo 声明先例）；`cmd`：`{k:'atk',entId?}`/`{k:'skill',idx:0|1|2,entId?,dir?}`/`{k:'recall'}`/`{k:'buy',item?}`/`{k:'ping',mark,x,y}`。10Hz 上报，静止报 `{mx:0,my:0}`（心跳兼保活）。
- **tick 内结算序**（S2 无确定性义务，语义稳定即可）：`inputs 应用（cmd 校验，reject 走 events）→ 移动/控制状态积分 → 草丛可见性 → 普攻计时+弹道推进+技能持续区 → 伤害结算（攻击者 id 升序，同 tick 原子）→ 死亡/推塔/营地裁决（ruling 事件）→ 复活/出兵/营地重生/经济 → AOI 过滤+脏标记 → 快照组包`。

### 5.2 AOI = 战争迷雾 + 草丛（mmo AOI 管线复用+视野玩法化）

- **AOI 半径 r=320px**（覆盖最长射程 260+边距；`snapshot.ext.aoi:{x,y,r}` 声明）——**视野圆即 AOI 圆**（与创意库 X-03"圈即 AOI"技术同源：S2 的 AOI 裁剪免费获得 MOBA 战争迷雾——圈外敌人不下发，客户端无从知晓）。野区支路因此天然是视野盲区（gank 的协议基础，零额外代码）。
- **草丛加层**：圈内实体若在草丛半径 55px 内且观察者不在同草丛 90px 内 → 该实体对本连接隐藏（服务端可见性过滤在 AOI 之后追加一道；被隐藏实体进 `leave`，露出时随下一张增量 `ents` 完整回归）。
- **预算分层**（mmo 先例）：塔/水晶/营地槽/草丛静态（join 全量+事件更新）；动态预算 40=英雄 6+兵 ≤8-12+被扰营地怪 ≤4+圣所怪 1 ≈ 峰值 23——**预算余量大**（§2.8a 兵线自均衡保证兵数有界）。
- **边缘抖动抑制**：15px 滞回带（入圆 320/出圆 335 才报 leave，mmo 同款）；草丛进出同样 10px 滞回。
- 玩家自身实体恒在 `ents` 首位（和解锚）；spectator 无自身实体，AOI 以镜头点为准（§5.4）。

### 5.3 S2/S5 边界：战斗事件 ruling 化论证（本作核心论证）

**命题**：MOBA 实时战斗（移动/普攻/弹道/持续区）走 S2 服务器权威状态；离散高利害节点（死亡/击杀/推塔/圣所/终局）**裁决化**——在 tick 结算末以原子裁决产出结构化 ruling 事件。**不做 S5 的 op→ruling 请求-应答回合机**。

| 维度 | S5 回合裁决（element-duel/tactics-duel） | 本作 S2 裁决化事件 |
|---|---|---|
| 决策频率 | 单拍：op 上行 → ruling 应答推进状态机 | 10Hz 连续积分；ruling 是**结果流**不是应答 |
| 通道 | 独立消息 `t:'op'`/`t:'ruling'` | `input.cmd` 上行 + `snapshot.events` 下发（零新消息类型） |
| 客户端角色 | 收 ruling 才推进（权威即呈现） | 客户端零判定；ruling 事件=juice 触发+账本，不作为状态源 |
| 适用判据 | 离散回合（出牌/走子，回合间无实时态） | 实时战斗中的离散高利害节点（毫秒级并发伤害的归属） |

**裁决化四规则**：

1. **原子死亡判定**：同 tick 全部伤害按攻击者 id 升序结算后，统一判死亡（HP≤0 即死，无中间态）——击杀者=最后有效伤害来源、助攻=5s 内参与伤害者，**一次 tick 一个唯一裁决**（双杀/反杀归属无歧义；塔/兵击杀 killer=-1 入 `byEnt` 字段）。
2. **ruling 事件形状**（账本三用：客户端 juice 零 diff 触发 / 结算页战报与成就回算 / api-check 断言锚——STRESS PM 全量回算先例）：`{k:'kill',frame,victim,killer,assists:[…],streak,bounty}` / `{k:'tower',frame,team,tid,by,teamGold}` / `{k:'core',frame,team}`（触发 `end`）/ `{k:'camp',camp,by,buff?}` / `{k:'shrine',frame,team}`（祝祷）。
3. **幂等与重连不重放**：重连走 welcome 全量 state（权威现状）；ruling 事件自 join 起续流，不回放历史（错过的高光由结算页战报补叙事）。
4. **弹道=轨迹事件**（带宽裁决）：技能弹道不入脏实体——`{k:'shot'}` 事件携带 from/dir/speed/maxDist，客户端本地呈现飞行（纯装饰外推，永不入状态）；**命中判定服务器权威**，命中时 `{k:'hit'}`+快照 hp 字段落地。星陨的 400ms 预警圈同理由事件携带（客户端画圈，服务器到点结算）。

**边界结论**：S5 的"服务器裁决"精神保留（唯一权威+结构化结果+可回算），S5 的回合状态机舍弃（实时战斗不能等往返）——这是 T2 款式与 T5 款式的本质分界，api-check 按 ruling 账本断言（§6）。

### 5.4 断线重连与观战位

- **重连**（协议 §2 10s+1 拍窗）：`join resume{seat,token}` → `welcome`（全量 state：英雄/等级/装备/金/位置/CD/复活计时/塔水晶血量/营地状态）→ 逐 10Hz 快照续流。**S2 无追帧负担**（不欠账），恢复 <1s，红线 10s 富余（mmo 同款论证）。逾时转 balanced 托管（§4.3）。
- **观战位**：满员（6/6）真人 → `spectate` 不占席收快照（协议 §2）；AOI 以镜头点为准（mmo 先例）。**导演模式**（默认开）：镜头自动追"团战焦点"——最近 8s 内 kill/tower/shrine ruling 事件位置加权质心，300ms lerp 切换；观战者可拖动临时接管镜头（5s 无操作回导演）。死亡视角观战队友同管线（§3.5）。
- `$sync`/`sync` 纠偏同全量路径。

### 5.5 200ms 延迟补偿（客户端预测子集，S7 完全体不采用论证）

- **本地移动预测**（mmo §5.5 全套范式）：摇杆输入即刻本地推进自身英雄——两端同一段纯函数（速度/边界/碰撞 AABB；碰撞表 join 下发），无外力时逐 tick 一致。**和解回路**：每张快照带 `ext.ack`（已处理输入 seq）+自身权威位置——丢弃 ack 前预测历史、重放未确认；误差 ≤32px 指数收敛（每帧 20%，~100ms 抹平）、>32px（被控/纠偏）200ms 快速滑移（不回滚闪跳）。
- **技能乐观表现**：前摇动画本地 0ms 起（权威校验 ≤1-2 快照，非法走 `reject` 事件回滚动画+CD 不扣）；伤害数字/命中特效**只等权威事件**（不预测数字——错了比慢了更伤手感）。
- **敌人 120ms 插值**（mmo §5.3 同款）：渲染延迟 120ms（上限 150ms 只上探不追快）、快照间线性插值、迟到航位外推 1 张。
- **200ms 可玩论证**：①移动 0ms 本地起步（指哪走哪）；②目标锁定制+方向自动仲裁（§1.6）——无瞄准精度惩罚；③普攻/技能为离散计时判定（攻击间隔 ≥0.9s）非逐帧碰撞——闪避靠位移决策不靠 16ms 精度；④TTK 8-12s 长窗（回滚价值低）；⑤弹道飞行 300-500ms 是天然延迟掩体。**不采用 S7 完全体**（speed-kart 影子预测+回滚）：本作无 50ms 级连续碰撞判定面，S2 预测子集（`ext.ack`，协议 §6 S7 位的 S2 实启）已覆盖全部延迟敏感操作——工程量与收益不成立（附决策 6）。
- **作弊面收口**：`atk/skill` cmd 服务器逐 tick 校验射程/CD/目标合法（隔空打/穿 CD 在服务端关死，mmo gather 校验先例）；草丛/AOI 可见性服务端过滤（客户端无从提前知晓，§5.2）。

### 5.6 带宽与 sim 负载预算

- **带宽/端**：常态增量 8-14 实体（6 英雄恒脏+兵 8）≈ **10-16KB/s**；团战峰值（满脏+弹道/命中事件）<25KB/s——高于 mmo（5KB/s，无战斗恒脏源）但与 speed-kart 20Hz 同量级；增量阈值兜底（§5.1）。6 玩家+2 观战网关侧 <150KB/s，轻。
- **sim 负载**：动态实体峰值 ~23+静态 15 ≈ 38 实体 10Hz——与 mmo 常态 30-40 同级，单房 CPU 可忽略；满编多房压测口径沿 STRESS 单既定框架。
