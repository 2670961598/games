# 竖屏小游戏品类与设计模式调研库

> 单据：GAMES-3 ｜ Epic：GAMES-1 ｜ 版本：v1（2026-09-21）
> 用途：后续批量游戏生产的设计弹药库。每品类一节，含核心循环 / 竖屏单手适配 / 参数化旋钮 / 参考数值 / 代表案例。
> 维护：新增品类沿用本文件节模板；数值区间为「休闲玩家首次可玩」基准，量产时按数值档位微调。

# 通用设计基线（全品类共享，各节只写品类特有内容）

### 拇指热区模型（单手竖持，右手）

- 参考画布：375×667 逻辑像素（iPhone SE/8 基准，安全区另算）。
- 舒适区：屏高 y > 40% 且屏宽 x ≤ 75%（拇指自然弧线扫过的右下大区；左手镜像）。
- 勉强区：y ∈ [25%, 40%]（需小指借力，长时间操作疲劳）。
- 死区：顶部 25% + 右上角（单手不可达，只放状态显示，不放交互）。
- 铁律：核心玩法交互全部落在屏高 2/3 以下；暂停/设置等低频按钮允许顶部但点击目标 ≥ 44×44pt。

### 竖构图三分区

| 分区 | 屏高占比 | 用途 |
|---|---|---|
| 状态区 | 顶部 20-25% | 分数、目标进度、金币、暂停入口（纯展示为主） |
| 玩法区 | 中部 45-55% | 主玩法发生地，允许全宽 |
| 操作热区 | 底部 25-33% | 拇指常驻区：按钮、瞄准基线、托盘、手势起点 |

### 单局时长三档

- 超短局 10-30s：失败即重开，天然广告插位（复活/跳过）。
- 标准局 30-90s：主流档位，关卡制品类默认。
- 长局 90-180s：Boss 局 / 资源关，占比 ≤ 全部关卡 15%。

### 难度曲线通用公式

- 关卡参数：`p(n) = p0 × k^(n/d)`，k∈[1.05, 1.15]，d=每 d 关参数翻倍的间隔。
- 前 10 关教学缓坡（k≈1.0-1.05，允许负反馈重玩）；第 11-30 关主升压段；30 关后进入 k≈1.02 的长尾（留给留存玩家）。
- 「心流阀门」：每 5 关插 1 关明显放松关（难度回落 20-30%），防连续挫败流失。

### 得分量级通用规范

- 单次有效操作得分：10-100 分（三位数感知最好）。
- 单局总分：1k-100k 量级；combo 倍率 1x-8x 封顶。
- 星级评价：3 星制阈值 = 目标分的 [60%, 85%, 100%] 或用时档位。

# 品类详录（24 类）

## 01 合成类（Merge，合成大西瓜式）

**核心循环**：等待投放 → 瞄准落点 → 释放投放 → 同级碰撞合成升级 → 空间被压缩 → 再投放。一次有效合成 5-15s，一局 2-5 分钟（空间耗尽结束）。
- 循环本质：空间资源管理 + 概率投放的即时反馈；「差一点就合成大的」是留存钩子。

**竖屏单手适配**：
- 投放口固定在玩法区顶部，落点瞄准线跟随拇指水平移动——拇指只在屏幕下半部左右滑动，不遮挡投放结果（结果发生在中下部）。
- 无任何按钮依赖：滑动=瞄准，松手=投放，天然单指。
- 竖直容器（宽度=屏宽，高度=屏高 70%）与重力方向一致，合成链可视化纵深感强（大水果沉底）。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 合成链长度 | 基础件到最终件的等级数 | 8-12 级 |
| 投放序列规则 | 纯随机 / 加权 / 只出前 N 级 | 前 3-5 级加权出现 |
| 容器形状 | 直筒 / 上宽下窄 / 障碍凸起 | 后期关卡引入凸起 |
| 合成体积比 | 新件面积/旧件面积 | 1.3-1.6（小于 1.3 拥挤感不足，大于 1.6 后期爆仓） |
| 结束线高度 | 溢出判定线距顶部比例 | 屏高 8-15% |

**参考数值区间**：
- 单局 2-5 分钟；新手前 3 局必出「差一级到顶」的近似通关体验。
- 得分按合成等级指数给：等级 L 合成分 = 2^L × 10。
- 难度旋钮主用「投放序列权重」：前 10 关只出前 3 级，之后逐关放开。

**代表案例**：《合成大西瓜》（MicroGames 爆款《Suika Game》西瓜游戏同构）、Merge Mansion（合成+剧情）、Merge Dragons!。

## 02 弹球/打砖块（Ballz 式回合消除）

**核心循环**：瞄准 → 发射一串球 → 观察碰撞清除砖块 → 砖块下压一行 → 再瞄准。一轮发射 3-10s，一局 3-5 分钟（砖块触底结束）。
- 循环本质：弹道规划的爽感 + 数字砖块的成长对赌（球数增长 vs 砖块血量增长）。

**竖屏单手适配**：
- 发射点在底部中央，拇指按住拖动瞄准（虚线预览弹道），松手发射——全交互在底部 1/3。
- 竖屏优势：砖阵纵向排布多、下压方向与重力一致，弹道纵向衰减小，一球多连的物理感比横屏更爽。
- 瞄准时手指遮挡发射器附近，需把弹道预览线画到屏幕中上部（手指上方留预览区）。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 初始球数 | 第一发球的数量 | 1-3 |
| 每关加球数 | 清空一行/拾取加号 | +1 每 1-2 行 |
| 砖块血量曲线 | 行数 n 的血量 | 5×1.12^n 起 |
| 下压间隔 | 每轮发射后下压行数 | 1 行/轮 |
| 特殊砖 | 加球/炸弹/分裂/护甲 | 3-6 种 |
| 弹射角度限制 | 最大入射角（防水平死循环） | ≥15° |

**参考数值区间**：
- 一局 3-5 分钟；「球数破百」的时刻应出现在第 8-15 次发射（心流峰值点）。
- 得分 = 消除砖块血量总和；单局 5k-50k。
- 关卡难度主升「血量曲线斜率」与「特殊砖稀缺度」。

**代表案例**：Ballz、BBTAN、Bricks Breaker Puzzle、微信《弹弹球》类小程序。

## 03 跑酷（竖向无尽/关制）

**核心循环**：自动前进 → 障碍/机会出现 → 拇指即时反应（跳/滑/变道）→ 得分/金币 → 速度提升 → 循环加压直到失误。单次反应 0.5-2s，一局 30s-3 分钟。
- 循环本质：反应速度与节奏感的自虐式追逐，「这次比上次更远」的比分驱动。

**竖屏单手适配**：
- 角色固定于屏高 60-70% 处（下方留反应预判区），障碍从上方涌入——竖屏纵深正好延长「看到→反应」窗口。
- 单指三手势任选其一为主：左右滑变道 / 上滑跳下滑滑 / 点按跳。避免同一品类内混用两种以上手势族。
- 拇指贴屏幕下半部滑动即可全程操作；变道类（地铁跑酷式）三车道宽度 = 屏宽 3 等分，滑动手感最稳。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 初速/极速 | 世界卷动速度 | 300→900 px/s（375 宽画布） |
| 加速曲线 | 每 10s 提速百分比 | +6-12% |
| 障碍密度 | 同屏障碍数期望 | 1.5-4 个 |
| 车道数 | 变道类 | 3（2 或 4 手感劣化） |
| 反应窗口 | 障碍出现到到达 | 1.2s（新手）→ 0.5s（后期） |
| 复活机制 | 观广告复活次数/局 | 1-2 次 |

**参考数值区间**：
- 一局 30s-3 分钟（失误率决定）；日均 8-15 局是健康留存信号。
- 距离得分 1 分/m + 金币 1 枚/个；combo 拾取连击 1.1x 步进。
- 难度主升速度与障碍组合复杂度（单障碍 → 双障碍 → 移动障碍）。

**代表案例**：Subway Surfers（地铁跑酷）、Chrome 恐龙跳跃、微信《全民飞跃》类、《是男人就下100层》（竖向反跑酷）。

## 04 三消（Match-3）

**核心循环**：观察盘面 → 找到可消除组合 → 交换 → 消除反馈 → 掉落补位 → 连锁/新机会出现 → 步数或目标消耗。一次交换 2-5s，一关 60-180s。
- 循环本质：受限步数内的目标求解（收集 X 个 Y），四消/五消/特效组合是技巧上限。

**竖屏单手适配**：
- 盘面居中偏下（操作区中心 ≈ 屏高 60%），顶部留目标/步数 HUD。
- 交互=相邻格点选或滑动交换，手指按压时遮挡 3×3 区域——靠「交换后掉落动画向上补」维持可视性；格子尺寸 ≥ 44pt（8×8 盘在 375 宽下格宽 44pt 是下限，故盘面 ≤ 9×9）。
- 竖屏盘面正方形占屏宽 95%，上下留白给 HUD 与特效演出，是三消的标准竖构图。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 盘面尺寸 | 行×列 | 6×6-9×9 |
| 步数预算 | 关卡给定步数 | 15-30 步 |
| 目标类型 | 收集/冰块/果冻/传送/限时 | 3-5 类轮换 |
| 掉落规则 | 有无洞/隔板/传送门 | 20 关后引入 |
| 特效件门槛 | 四消/五消/L/T 消 | 前者必配，后者 10 关后 |
| 初始死局率 | 开局无可消概率 | <2%（需自动洗牌兜底） |

**参考数值区间**：
- 一关 60-180s；步数余量 0-3 步通关占比应约 30%（紧张感）。
- 分数 = 基础 20 分/件 × 连锁倍率（1.0/1.2/1.5/2.0）；三星线 1x/1.5x/2x 于一星线。
- 难度主升步数收紧与目标量提升，而非盘面复杂度（后者的挫败是坏挫败）。

**代表案例**：Candy Crush Saga（糖果传奇）、开心消消乐、Royal Match、Gardenscapes（三消+装修双层结构）。

## 05 放置点击（Idle/Clicker）

**核心循环**：点击产出 → 攒货币 → 买升级 → 自动产出提升 → 挂机 → 回收爆仓收益 → 再升级。单次会话 30s-3 分钟，长循环以小时/天计。
- 循环本质：指数成长曲线的「数字变大」多巴胺 + 离线收益的回访钩子。

**竖屏单手适配**：
- 主点击目标（大按钮/角色）放屏高 55-75% 处，拇指最省力区域；点击判定半径 ≥ 64pt（容错大点击才爽）。
- 商店/升级列表在下半屏可单指滚动，每行「买入」按钮靠右下角（右手拇指落点）。
- 竖构图信息排布：顶部数值总览（每秒产出）、中间点击主体、底部升级列表——竖屏列表天然适合长升级栏。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 基础点击产值 | 每次点击 | 1（量纲起点） |
| 升级成本曲线 | 第 n 级成本 | cost0 × 1.15^n（放置类黄金斜率） |
| 产出曲线 | 第 n 级产出 | prod0 × 1.08^n（与成本差制造瓶颈） |
| 离线收益效率 | 离线/在线产出比 | 40-60% |
| 离线封顶 | 最大累积时长 | 8-24h（逼回访） |
| 声望/转生 | 重置换取全局倍率 | 首次转生在 3-7 天进度点 |

**参考数值区间**：
- 会话 30s-3 分钟 × 每日 5-10 次；数字量级从 10 到 10^12（科学计数法 UI 必备）。
- 升级档位「买得起间隔」：约 2-5 分钟一个新可买项（前期 30s，后期拉长）。
- 难度=成长瓶颈位置；调 1.15 的成本斜率即可整体调节奏。

**代表案例**：Cookie Clicker（饼干点点点）、Clicker Heroes、AdVenture Capitalist、放置奇兵。

## 06 答题/猜谜（Quiz）

**核心循环**：出题 → 阅读（2-10s）→ 选择/输入 → 即时判分反馈 → 下一题/结算。一题 5-20s，一局（10-20 题）2-4 分钟。
- 循环本质：知识获得的自我确认 + 计时压力下的果断感；题库深度=内容弹药。

**竖屏单手适配**：
- 题干占屏中部 30-40%（字号 ≥ 17pt，≤4 行）；选项 2×2 或 1×4 按钮占下半屏，每按钮 ≥ 56pt 高。
- 单指即可全流程（点选项即确认，或点选+右下角确认钮二段式防误触）。
- 倒计时条横贯题干下方，进度感知不占交互区。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 每题限时 | 单题倒计时 | 10-20s |
| 选项数 | 干扰项数量 | 4（文字）/ 6-9（图片） |
| 题库规模 | 总题量 | ≥500 起，按主题分包 |
| 连答奖励 | 连续答对加成 | +10%/连，封顶 +100% |
| 生命/错误容忍 | 一局可错数 | 3 错出局（标准大逃杀式）或无限制练习式 |
| 题型混排 | 单选/多选/图片/排序 | 2-4 种 |

**参考数值区间**：
- 一局 2-4 分钟；答题正确率目标带 65-80%（低于 60% 弃局）。
- 得分 = 100 + 时间奖励（0-100）+ 连击奖励；单局 1k-3k。
- 难度=题库分级（按历史正确率动态调，ELO 式出题）。

**代表案例**：头脑王者、HQ Trivia、疯狂猜图、微信《知识竞赛》类小程序。

## 07 找茬（Spot the Difference）

**核心循环**：对比两图 → 发现差异点 → 点击标记 → 进度+1 → 计时消耗 → 全部找齐/超时结算。找一处 5-60s，一局（5-8 处）1-3 分钟。
- 循环本质：视觉搜索的「顿悟」快感；差异点难度梯度=内容设计深度。

**竖屏单手适配**：
- 竖屏双图排布：上下堆叠（各占屏高 35-40%），点击任一图对应位置都算——拇指只操作下半图，上半图靠注视（点不达但看得到，差异点在下半图出现率应 60%+ 保证单手可玩）。
- 单指点击即全部交互；放大镜道具按钮放右下角。
- 上下排布比左右排布更优：单图更大、对比视线移动短（上下扫视比左右扫视省劲）。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 差异数 | 每关找茬点数 | 5-8 |
| 限时 | 一关总时长 | 60-120s |
| 差异类型 | 色差/缺物/镜像/尺寸 | 由易到难引入 |
| 差异尺寸 | 差异区域直径占图比 | 1-5% |
| 提示道具 | 高亮一块区域 | 1-3 次/关（广告换） |
| 场景复杂度 | 底图元素密度 | 10-40 个视觉组块 |

**参考数值区间**：
- 一局 1-3 分钟；平均每差异点耗时 10-30s（超过 45s 应给软提示如闪烁边缘）。
- 得分 = 剩余时间 ×10 + 差异数 ×100；提示使用扣 30%。
- 难度主升差异尺寸缩小与干扰元素密度，不砍时间（时间是紧张感不是难度本体）。

**代表案例**：大家来找茬（经典 Flash/街机）、微信小程序《找茬大师》类、《汉字找茬王》（文字变体，爆款）。

## 08 涂色（Paint by Number）

**核心循环**：选色号 → 点击对应编号区域 → 区域填充 → 完成一个色号 → 换下一色 → 整图完成结算。一次点击 1-3s，一图 3-20 分钟（可中断续涂）。
- 循环本质：零失败压力的整理癖满足；成品分享是传播钩子。

**竖屏单手适配**：
- 画布铺满屏（双指缩放辅助，但核心填色=单指点击）；色号托盘横排底部，当前色高亮放大。
- 点击目标区域判定按「编号区域」整块命中，不需精确到像素（容错=爽点）。
- 竖构图：画布全屏 + 底部 64pt 色盘托盘；顶部分类/进度只读。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 色号数 | 单图颜色数 | 8-24 |
| 区域数 | 单图填充块数 | 100-800 |
| 区域最小面积 | 最小块像素 | ≥ 6×6 显示像素（缩放后） |
| 完成时长 | 单图纯操作时间 | 3-20 分钟 |
| 魔法笔 | 长按自动连续填充同号区 | 30 关后解锁 |
| 图库主题 | 风格包 | 儿童/风景/名画/IP 联动 |

**参考数值区间**：
- 单图分 2-5 个会话完成（自动存档）；会话 2-5 分钟。
- 无分数体系，进度=完成百分比 + 图章收集；每日新图 1-2 张驱动回访。
- 难度即色号数与区域密度，线性即可，不需要难度曲线（此品类反内卷）。

**代表案例**：Happy Color、UNICORN 数字涂色、Paint by Number、微信《数字油画》类小程序。

## 09 节奏（Rhythm，钢琴块式）

**核心循环**：块随音乐下落 → 到达判定线时点击 → 命中反馈（音+光）→ 连击积累 → 速度渐升 → miss 断连/失败。单次点击间隔 0.3-1s，一局 60-180s。
- 循环本质：音画同步的本能爽感 + 手速极限挑战；曲目=内容弹药。

**竖屏单手适配**：
- 钢琴块式块体从上下落，判定线放屏高 75-85% 处（拇指点击区上缘），块在上方视野区被预读，到判定线时被拇指点击——判定线不能贴底（拇指遮挡区）也不能太高（反应窗口不足）。
- 双手四轨是经典，但单手版=2-3 轨 + 轨宽加大（≥ 110pt），或「任意轨点击」（timing-only 制）。竖屏单手版建议 2 轨（左右半屏）或 1 轨纯节奏。
- 拇指遮挡判定线下方 10-15% 屏高，判定线应落在拇指上缘（屏高 80% 左右），下落块在上方视野区。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 轨道数 | 下落轨道 | 1-4（单手 ≤3） |
| 下落速度 | 块从顶到判定线时长 | 1.8s（慢）→ 0.5s（快） |
| 判定窗口 | Perfect/Great/Miss 容差 | ±50/±100/±180 ms |
| 块密度 | 每秒平均块数 | 1-4 |
| 倍速阶段 | 曲内加速档 | 1.0x/1.25x/1.5x |
| 生命制 | miss 扣血 vs 直接失败 | 前期血制（3-5 miss），后期一击制 |

**参考数值区间**：
- 一局=一首曲 60-180s；连击数 50-500。
- 得分 = 块基础分（Perfect 100/Great 60/Miss 0）× 连击系数（1 + combo×0.01，封顶 3x）。
- 难度=曲目谱面分级（E/N/H 预生成：块密度与同步率双轴）。

**代表案例**：钢琴块 2（Piano Tiles 2）、节奏大师、别踩白块、Dancing Line（单指变体）。

## 10 堆叠（Stack，叠塔）

**核心循环**：积块左右往复移动 → 时机点击放置 → 多余部分被切掉 → 塔变窄 → 失误到宽度归零结束。一次放置 1-3s，一局 30-120s。
- 循环本质：时机精度挑战 + 塔高的可视化成就（“这一局我盖了 50 层”）。

**竖屏单手适配**：
- 塔固定屏幕中轴，镜头随塔上移（塔顶保持屏高 45% 附近），点击屏幕任意位置=放置（无瞄准，纯时机）。
- 单指单点击全交互，零学习成本。
- 竖屏纵深=塔高可视化天然主场；横屏此品类不成立。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 块移动速度 | 往复周期 | 1.6s → 0.6s 随层数提升 |
| 初宽 | 起始块宽 | 屏宽 50-60% |
| 切除惩罚 | 未对齐部分整块切掉 | 完全对齐 +奖励加宽 1-4pt |
| 完美奖励 | 连续 Perfect 效果 | 宽度回升 + 特效 + 分数倍率 |
| 块形状 | 方块/圆柱/异形 | 3-5 种轮换 |
| 颜色渐变 | 塔身配色漂移 | 每 10 层换色系（视觉进度） |

**参考数值区间**：
- 一局 30-120s；玩家分布中位数 15-30 层，高手 60+。
- 得分=层数 ×（1+perfect 连数×0.1）；单局 100-2000。
- 难度=速度曲线；`speed(n) = 1.6 × 0.985^n` 封底 0.6s。

**代表案例**：Stack（Ketchapp）、Tower Bloxx、微信《叠方块》类、《超级叠叠乐》小程序。

## 11 弹射（Slingshot，愤怒的小鸟式）

**核心循环**：拖拽瞄准 → 松手弹射 → 物理破坏 → 目标受损/倒塌 → 剩余弹药结算星级 → 下一关。一次弹射 5-15s（含观察），一关 1-3 分钟。
- 循环本质：抛物线直觉的物理爽感 + 破坏反馈；弹药余量=技巧压力。

**竖屏单手适配**：
- 弹弓固定左下（或底部中央），拇指拖拽方向=反向拉弓（拖左下瞄准右上），手指移动全在下半屏。
- 瞄准辅助：拖拽时显示轨迹预测点（前 5-8 个落点），抵消手指遮挡。
- 竖屏抛物线优势：高抛弹道可视化空间大（屏高=射高）；关卡纵深化（目标叠高而非摊横）。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 弹药数/关 | 可发射次数 | 3-8 |
| 弹体种类 | 普通/加速/分裂/重锤 | 2-5 种 |
| 初速系数 | 拉满时速度 | 800-1200 px/s |
| 重力 | 世界重力 | 1200-2000 px/s² |
| 目标耐久 | 木/石/冰材质血量 | 1/3/6 档 |
| 结构高度 | 关卡搭高 | 3-8 层 |

**参考数值区间**：
- 一关 1-3 分钟 × 重试 1-3 次；通关用弹 ≤ 60% 弹药=三星线。
- 得分 = 目标分 + 剩余弹药×10000（弹药奖励占 20-40% 制造碾压爽感）。
- 难度主升结构稳定性（更难倒塌）与目标保护位置，而非减弹药。

**代表案例**：Angry Birds（愤怒的小鸟）、Bubble Witch、微信《愤怒的小鸟》小程序复刻、《皇家弹射》类。

## 12 塔防-lite（Tower Defense Lite）

**核心循环**：敌人沿路径进攻 → 玩家布防/升级塔 → 波次推进 → 金币收益再投资 → 守住/漏怪扣血 → 波次清空胜利。一波 15-45s，一关 3-6 波 2-5 分钟。
- 循环本质：资源分配的即时验证（造对塔=怪死得快）；lite 版砍科技树、砍到 3-4 种塔。

**竖屏单手适配**：
- 路径盘面全屏展示，点空地=弹建塔菜单（按钮环绕点击点，半径 80pt 内，拇指可达），点塔=升级/出售菜单。
- 竖屏路径设计：S 形纵贯（入口顶部、出口底部），塔位沿路径两侧——竖构图纵深远大于横屏塔防的摊大饼。
- 波次间「下一波」按钮放底部中央（拇指休整位），双倍速按钮右下角常驻。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 塔种类 | 可建塔类型 | 3-4（lite 上限） |
| 塔升级级数 | 单塔等级 | 3 级 |
| 波次数 | 每关波数 | 3-8 |
| 敌人类型 | 普通/快速/坦克/空军 | 3-5 种 |
| 出怪间隔 | 同波刷新间隔 | 0.8-1.5s |
| 初始金币 | 开局资金 | 恰好 1 塔 + 1 升级 |
| 血量曲线 | 第 n 波敌人血量 | hp0 × 1.18^n |

**参考数值区间**：
- 一关 2-5 分钟；漏怪容忍 10-20 血（总 20 血，漏 3-4 个普通怪）。
- 得分=剩余血量×1000+击杀×10；星级按血量 100%/60%/30%。
- 难度主升血量斜率与新敌人组合，塔数值不动（保持玩家心智模型稳定）。

**代表案例**：植物大战僵尸（PvZ，塔防-lite 鼻祖级）、保卫萝卜、Bloons TD 竖屏变体、微信《塔防小游戏》类。

## 13 贪吃蛇变体（Snake）

**核心循环**：蛇自动前进 → 转向决策（点/滑） → 吃食物变长 → 空间收缩/自撞风险升 → 撞墙/撞己结束。一次决策 0.3-1s，一局 1-3 分钟。
- 循环本质：空间预判 + 风险胃口（越长分越快但越险）；变体空间大（大作战式 io 化）。

**竖屏单手适配**：
- 操作三选一：①屏幕左右半区点按转向（贪吃蛇大作战式，最荐）②四向滑动手势 ③虚拟摇杆（单手劣化，不荐）。
- 竖屏方形盘面居中，四周留 8-12pt 边框显示墙；蛇身粗 ≥ 12pt。
- io 变体（大作战）：镜头跟随蛇头，蛇头保持屏中央，食物散布全图——拇指点击转向即可。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 移速 | 每秒格数 | 4-10 格/s |
| 加速机制 | 长按冲刺（牺牲长度） | 变体标配 |
| 盘面尺寸 | 网格行列 | 15×15-25×25 |
| 食物价值 | 普通/特殊/敌对 | 1/5/风险诱饵 |
| 障碍物 | 场内石块数 | 0-8（难度内容） |
| 穿墙规则 | 撞墙死 vs 环面穿越 | 新手局环面，标准局撞墙死 |
| AI 蛇数量 | 大作战变体 | 5-15 条 |

**参考数值区间**：
- 一局 1-3 分钟；长度 10-100+。
- 得分=食物数 ×（1 + 长度/50）；单局 100-2000。
- 难度=移速曲线与障碍密度；`speed(n) = 4 + n×0.1`（n=当前长度）。

**代表案例**：贪吃蛇大作战、Slither.io、经典 Nokia Snake、微信《蛇蛇争霸》类小程序。

## 14 2048 变体（数字滑合）

**核心循环**：观察数字盘 → 滑动合并等值件 → 数字翻倍 → 新件补充 → 空间收缩 → 无路可走结束。一次滑动 2-5s，一局 5-15 分钟。
- 循环本质：空间资源管理 + 数字的指数成长可视化；「差一点出 2048」执念是核心留存。

**竖屏单手适配**：
- 盘面居中（4×4 格，格宽 = 屏宽/4.5），四向滑动手势全屏任意位置可起手——拇指轻扫即全部操作。
- 滑动方向判定阈值 ≥ 24pt 防误触；撤销按钮放底部（每局限 1-3 次）。
- 竖构图：顶部分数+最高块 HUD，中部盘面，底部「新局/撤销」双按钮。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 盘面尺寸 | 行×列 | 4×4（经典）/ 5×5（简单）/ 3×3（极难） |
| 新件概率 | 2 vs 4 出现比 | 9:1（经典） |
| 每步新件数 | 单次滑动补充数 | 1（经典）/ 2（hard 模式） |
| 目标数值 | 终局数字 | 2048/4096/∞ |
| 特殊格 | 锁定格/穿升格/雷格 | 变体引入 |
| 撤销次数 | 回退步数 | 1-3 或无 |

**参考数值区间**：
- 一局 5-15 分钟（中断友好，自动存档必须）。
- 得分=每次合并的新数值之和；出到 2048 累计约 20k 分。
- 难度=盘面尺寸与新件概率；3×3 盘是天然 hard 模式。

**代表案例**：2048（Gabriele Cirulli 原版）、Threes!（小 3 传奇，《2048 之父》）、微信《2048》各变体、《合并数字》类小程序。

## 15 割绳子变体（Cut the Rope 式物理谜题）

**核心循环**：观察悬挂结构 → 划线切断绳索 → 重力/摆动物理生效 → 糖果路径改变 → 收集星星/喂到怪物 → 失败重试。一次切割尝试 5-20s，一关 30s-3 分钟。
- 循环本质：物理因果的试错解谜（切序即解法）；「差一点」的物理抖动制造重试动力。

**竖屏单手适配**：
- 划线切割=单指手势，任意角度短划（≥ 20pt 轨迹）即切；绳索结构占屏中部 50%。
- 拇指划线会遮挡下部——关键结构（第一个绳结）应布置在屏高 40-70% 区；重试按钮底部大按钮。
- 竖屏摆锤物理纵深好：糖果下落行程长，反应窗口充足。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 绳索数 | 单关可切绳数 | 1-6 |
| 收集星数 | 关卡内星星 | 3（经典） |
| 物理元件 | 气球/气垫/传送/磁铁 | 4-8 种逐关引入 |
| 切割次数限制 | 部分关卡限定刀数 | ∞（新手）/ 1-3（谜题关） |
| 时间要素 | 部分关卡限时 | 20-40s 或无 |
| 摆动周期 | 绳摆固有频率 | 1-2.5s（可读性窗口） |

**参考数值区间**：
- 一关 30s-3 分钟（含重试 1-3 次）；三星=一次切完+全星+短时。
- 星级判定：星数即星级（3 星制与收集物合一）。
- 难度=元件组合复杂度（先单元件熟练→多元件组合），不砍容错。

**代表案例**：Cut the Rope（割绳子）、Where's My Water（鳄鱼爱洗澡，同构变体）、微信《割绳子》复刻类。

## 16 跳一跳变体（按蓄力跳距）

**核心循环**：按住蓄力（读条/压缩动画）→ 松手起跳 → 落点判定（中心加成）→ 下一个平台出现 → 循环直到落空。一次跳跃 1-3s，一局 30s-3 分钟。
- 循环本质：力度直觉的校准挑战（肌肉记忆）；连中心=风险偏好自选（稳 or 浪）。

**竖屏单手适配**：
- 按住屏幕任意位置蓄力（无按钮），松手跳——单指零位移操作，疲劳度极低。
- 角色固定屏高 60% 处，镜头跟随；蓄力压缩动画在小人本体（视觉焦点=操作反馈合一）。
- 竖屏=跳距纵深可视化主场（跳距可达屏高 1.5 倍），平台间距随机漂移制造读距挑战。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 蓄力-跳距映射 | 按住 t 秒的跳距 | d = v×t（线性）或分段 |
| 最大跳距 | 蓄满上限 | 屏高 1.2-1.8 倍 |
| 平台尺寸分布 | 半径随机范围 | 20-60pt，越远越小 |
| 平台间距分布 | 相邻距离随机 | 40-400pt（后期拉开） |
| 中心奖励 | 落中心加成分 | +2/4/8...（连击翻倍） |
| 平台类型 | 静止/移动/消失/弹性 | 4 种逐段引入 |

**参考数值区间**：
- 一局 30s-3 分钟；中位数跳跃 15-40 次。
- 得分：普通落地 1 分，中心连击 2/4/8/16 封顶；单局 10-500。
- 难度=平台间距分布右移与特殊平台占比；`gap_max(n) = 200 + n×2` 封顶 400。

**代表案例**：微信《跳一跳》（现象级）、Doodle Jump（弹跳变体、同屏蓄力改自动）、微信小程序《跳跳》各复刻。

## 17 接金币（Catch'em All 式托盘接物）

**核心循环**：物品从顶部落下 → 左右移动托盘接住 → 空气/炸弹要躲 → 漏接扣命 → 时限/命尽结算。一次接取 0.5-2s，一局 60-180s。
- 循环本质：简单的追踪反应 + 排除干扰（好物/坏物二分）；适合做超短局广告位载体。

**竖屏单手适配**：
- 托盘在屏高 80-88%，拇指左右滑动直接控制托盘 x（1:1 跟手或速度映射）；落物全程可视（顶部→托盘的行程即反应窗口）。
- 单指滑动全交互；托盘宽 60-90pt（比物宽 2-3 倍，容错感）。
- 竖构图天然分工：上半屏=物源区（看清是什么），下半屏=操作区（接）。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 落速 | 物品下落速度 | 150→450 px/s 随时间升 |
| 生成间隔 | 新物间隔 | 1.2s → 0.4s |
| 好坏物比 | 金币:炸弹 | 4:1 → 2:1 |
| 托盘宽度 | 接取面宽 | 屏宽 20-30% |
| 生命/漏接容忍 | 漏好物扣命 | 3 命制或时间制 |
| 特殊物 | 大金币/磁铁/减速/炸弹 | 3-5 种 |
| 连击 | 连续接住奖励 | +5%/连 封顶 +100% |

**参考数值区间**：
- 一局 60-180s；接住数 30-150。
- 得分=物品值×连击系数；单局 500-10k。
- 难度=落速与生成间隔双升；`fall(t) = 150 + 2×t`，`spawn(t) = max(0.4, 1.2 - 0.005×t)`（t 秒）。

**代表案例**：4399《接金币》Flash 经典、微信《接元宝》类小程序、蛋仔派对内嵌《疯狂接糖》类、Chrome 恐龙（同构：躲→接的反向）。

## 18 躲避类（Dodge，Flappy 式）

**核心循环**：障碍逼近 → 微操调整位形 → 穿越间隙 → 得分+1 → 速度/密度提升 → 碰撞即死 → 一键重开。一次穿越 0.5-2s，一局 10-90s。
- 循环本质：极简规则 + 即时死亡的高张力；「再来一次」成本趋近于零是留存核心。

**竖屏单手适配**：
- 点按=上升、重力=下坠（Flappy 式），或左右滑=平移（飞机大战式）——均单指。
- 角色固定屏高 30-40%（左侧），障碍从右向左；竖屏的优势是上下躲避空间大（障碍纵向排布）。
- 死亡→重开按钮放屏幕下半（拇指位），且「点按任意处重开」更佳（重开摩擦最小化）。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 障碍间隙 | 通过窗口尺寸 | 角色尺寸的 2.5-4 倍 |
| 障碍间距 | 相邻障碍水平距离 | 屏宽 50-80% |
| 移速 | 世界速度 | 150→300 px/s |
| 重力/推力 | Flappy 式升降参数 | g=1800, F=-450 px/s²（帧率无关化） |
| 障碍运动 | 静止/上下振荡/旋转 | 3 档逐段引入 |
| 得分节奏 | 每越一障得分 | 1 分（纯粹）或渐增 |

**参考数值区间**：
- 一局 10-90s（死亡游戏，短就是设计）；重开间隔 <1s。
- 分数=穿越数；中位数 3-10，高手 50+（分享截图的分数阶梯）。
- 难度=间隙收缩与移速；前 5 次穿越保持教学宽松（间隙 4 倍）。

**代表案例**：Flappy Bird（现象级）、微信《飞机大战》（全民）、Space Invaders 竖屏变体、《是男人就坚持 30 秒》（弹幕躲避）。

## 19 翻牌记忆（Memory Match）

**核心循环**：翻两张牌 → 判断配对 → 配对成功消除/失败盖回 → 记忆位置信息积累 → 全部配对完成结算。一次翻牌 2-5s，一局 40s-3 分钟。
- 循环本质：工作记忆的自我挑战；无时间压力版是「休闲喘息品类」，限时版是紧张感变体。

**竖屏单手适配**：
- 牌阵网格居中（4×4 起，牌尺寸 ≥ 72pt），单指点击翻牌即全部交互。
- 竖构图分层：顶部 HUD（翻牌次数/计时/连对），中部牌阵，底部道具（洗牌透视提示）。
- 牌阵行列随难度增：4×4→4×5→5×6→6×6（6×6=36 张已接近记忆上限，再大需道具辅助）。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 牌数 | 总卡牌数 | 8-36 |
| 牌面素材类型 | 图案主题包 | 每包 18-40 图 |
| 翻牌失败展示时长 | 盖回前的记忆窗口 | 0.8-1.5s |
| 限时 | 关卡时限 | 无 / 60-180s |
| 连对奖励 | 连续配对加成 | +10%/连 |
| 道具 | 透视 1 张 / 自动配对 1 组 | 1-2 次/局 |
| 干扰机制 | 部分牌会换位（高级） | 20 关后引入 |

**参考数值区间**：
- 一局 40s-3 分钟；完成翻牌次数 = 牌数 × (1.2-2.2)（越接近 1.2 记忆表现越好）。
- 得分 = 牌对基础分 × 连对系数 − 超时惩罚；三星按翻牌次数档位。
- 难度=牌数与干扰机制，限时版再叠加时间。

**代表案例**：经典 Memory/Pairs（实体牌移植）、微信《翻牌消消看》类、《记忆大师》脑力小程序、连连看（同构变体：记忆+路径判定）。

## 20 数字华容道（滑块归位）

**核心循环**：观察空位与块位 → 滑动可动块 → 目标数字逐步归位 → 步数消耗 → 全部有序通关。一步 1-3s，一关 1-5 分钟。
- 循环本质：置换群的空间推理（每一步都在影响后续可解性）；步数越少越强的优化驱动。

**竖屏单手适配**：
- 盘面居中（4×4 标准，格宽 ≥ 80pt），单指滑动块或滑动方向即全部操作（滑块跟随手指或按方向步进两种手感）。
- 竖构图：顶部目标图示（1-15 有序参考）+ 步数计时，中部盘面，底部「重排/提示」按钮。
- 块面数字要大（≥ 格宽 60% 的字号），老年玩家是重要受众。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 盘面尺寸 | n×n | 3×3（入门）/ 4×4（经典）/ 5×5（进阶） |
| 打乱步数 | 生成时随机步数 | 50-200（保证可解性：从终局倒推打乱） |
| 步数基准 | 三星步数线 | 打乱步数 × 1.2-1.5 |
| 限时 | 挑战模式 | 无 / 3-10 分钟 |
| 目标形态 | 顺序排列 / 图案复原 | 2 种 |
| 提示 | 高亮下一步最优块 | 3 次/关（广告换） |

**参考数值区间**：
- 一关 1-5 分钟（4×4 打乱 100 步，普通玩家 150-300 步复原）。
- 星级按步数：≤1.2x 基准 3 星、≤1.8x 2 星、通关 1 星。
- 难度=盘面尺寸与打乱步数；保证可解必须用「从终局随机走」生成而非随机排列（随机排列 50% 不可解）。

**代表案例**：数字华容道（微信小程序爆款）、《华容道》经典实体移植、Unpuzzle、Klotski 滑块箱（变体：块形状异形化）。

## 21 文字类（Wordle/成语接龙式）

**核心循环**：读题面（字/词条）→ 输入或点选猜测 → 反馈（颜色标记/对错）→ 收窄候选空间 → 命中/用尽次数结算。一回合 10-60s，一题 30s-5 分钟。
- 循环本质：语言知识的排除法推理（信息熵逐减）；每日一题=社交裂变钩子（无 spoiler 分享）。

**竖屏单手适配**：
- 输入方式两档：①点选候选字/字母块（中文品类主流，单指友好）②底部系统键盘（英文 Wordle 式，键盘贴底拇指区）。
- 中文变体：字阵网格点选（9-16 宫格字块连线成语），连线手势=单指拖动。
- 竖构图：顶部题面/格子区（结果可视化），底部输入区（键盘或字阵），中间反馈动画。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 词长 | 目标词字数 | 2-4 字（成语）/ 4-6 字母（英文） |
| 猜测次数 | 上限次数 | 4-6 次 |
| 候选字阵 | 干扰字数 | 9-16 宫 |
| 反馈粒度 | 位置对/存在/无 | 三色制（Wordle 标准） |
| 词库规模 | 题库量 | ≥1000 词条，按难度分级 |
| 提示 | 揭示一个字/排除 N 个 | 1 次/题 |
| 每日题 | 全球同题制 | 1 题/天（社交裂变核心） |

**参考数值区间**：
- 一题 30s-5 分钟；4 猜内命中率目标 40-70% 分布。
- 得分=剩余次数×100+连胜奖励；连胜 streak 是核心展示资产。
- 难度=词频分级（常用词→生僻词）与干扰字相似度（形近字/音近字）。

**代表案例**：Wordle（全球现象级）、成语接龙/疯狂猜成语（微信小程序主流）、《汉字找茬王》字类混合、Scrabble 变体。

## 22 物理投掷（Paper Toss 式）

**核心循环**：瞄准（力度+角度）→ 投掷 → 物理飞行（受干扰力）→ 命中/落空反馈 → 距离/连中推进 → 用尽次数结算。一次投掷 3-10s，一局 1-3 分钟。
- 循环本质：抛物线手感校准（与跳一跳同族，但换成显式投射物）；连中 combo 是爽点主源。

**竖屏单手适配**：
- 拖拽投掷（从物到目标反向拉，弹弓同构）或点按蓄力两段式；拖拽起手点在屏下半。
- 轨道预览虚线（前段）+ 落点抛物线记忆（上一次落点标记）抵消手指遮挡。
- 竖屏=投掷纵深（目标在上方/远处），风力/干扰指示器放顶部状态区。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 干扰力 | 风/重力偏移 | 0-3 档（可视化为风向标） |
| 目标尺寸 | 命中区半径 | 30-80pt，距离越远越小 |
| 目标距离 | 投掷行程 | 屏高 0.5-2 倍 |
| 连中倍率 | 连续命中加成 | +20%/连 封顶 3x |
| 弹药/时限 | 一局资源 | 5-10 次或 60-120s |
| 弹道类型 | 直线/抛物线/反弹 | 1-3 种混布 |

**参考数值区间**：
- 一局 1-3 分钟；命中率新手 30%，熟练 70%+。
- 得分=命中分×连中倍率+距离加成；单局 100-3k。
- 难度=干扰力档位与目标距离；距离对得分的贡献应高于尺寸收缩（鼓励冒险）。

**代表案例**：Paper Toss（扔纸团，经典）、微信《投篮高手》类、《巅峰投球》 Baseball 变体、水果忍者（同族变体：投掷改切割）。

## 23 转盘/抽签（Wheel of Fortune 式轻决策）

**核心循环**：选择启动（点按/拨动）→ 转盘旋转（悬念 2-5s）→ 减速停止 → 结果揭晓（奖励/惩罚/决策）→ 领取 → 冷却/再来。一轮 5-10s。
- 循环本质：间歇性变量奖励（老虎机内核）；作为独立游戏单薄，作为元系统（任务奖励可视化）极强。

**竖屏单手适配**：
- 转盘居中（直径=屏宽 70-85%），中心「GO」按钮或底部拨杆启动；单指拨动转盘边缘赋予初速（手感版）或纯点按（简化版）。
- 结果指针在盘顶 12 点方向（视线焦点），奖励结算弹窗按钮底部。
- 竖构图：顶部次数/货币，中部大盘面，底部启动+分享按钮。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 扇区数 | 奖励分区数 | 6-12 |
| 概率分布 | 各扇区权重 | 加权随机（视觉等分但权重不同是行业默认，注意合规标识） |
| 旋转时长 | 悬念期 | 2-5s（缓动减速曲线） |
| 旋转表现 | 圈数+末段蠕动 | 4-8 圈 + 末段 1-2 次停顿感 |
| 抽取次数 | 免费/付费/广告 | 每日 1-5 免费 + 广告补次 |
| 保底机制 | N 抽必出高档 | 10-50 抽（防流失） |

**参考数值区间**：
- 一轮 5-10s（纯等待 2-5s 是悬念甜区，超过 6s 焦躁）。
- 奖励量级挂钩主经济系统；高档区视觉面积占比 ≤ 15%（稀缺暗示）。
- 「难度」不适用；调的是概率分布与冷却节奏（留存参数）。

**代表案例**：幸运大转盘（营销活动标配）、Coin Master 转盘（核心玩法化）、旅行青蛙的抽奖（轻量变体）、微信小程序《决定轮盘》（决策工具向）。

## 24 模拟经营-lite（Idle Management Lite）

**核心循环**：接待顾客 → 赚取金币 → 升级设施/雇员 → 产能提升 → 顾客流/单价提升 → 循环扩张。单会话 1-3 分钟，长线以天计。
- 循环本质：可见的资产滚雪球（与放置同族）+ 布局规划的轻策略；「我的店越来越忙」是情感钩子。

**竖屏单手适配**：
- 场景全屏俯视/斜视，点按顾客/设备即交互（接单、收钱、修复）；单指点按为主+双指缩放（可选）。
- 高频点击点（收钱气泡）生成区域集中在屏中下部；顶部数值 HUD 只读。
- 竖构图纵向分层：顶层 HUD、中层经营场景（2-4 条服务线纵向排布）、底部升级栏/商店切换 Tab。

**参数化旋钮**：

| 旋钮 | 含义 | 建议区间 |
|---|---|---|
| 服务线条数 | 并行产线 | 2-4 条 |
| 顾客到达率 | λ（泊松） | 0.2-2 人/s 随星级升 |
| 耐心值 | 等待容忍时长 | 10-30s（超时流失） |
| 升级成本曲线 | 设施 n 级成本 | cost0 × 1.2^n |
| 产出曲线 | 设施 n 级收益 | prod0 × 1.12^n |
| 离线收益 | 挂机产出比 | 30-50% 封顶 4-12h |
| 雇员自动化 | 招聘解锁位 | 每条线 1-3 个自动化位 |

**参考数值区间**：
- 会话 1-3 分钟 × 每日 4-8 次；单服线回本周期 2-5 分钟（会话内即时验证）。
- 经济数值从「单价 10」到「单价 10^6」；断点扩展用「开分店/开连锁」承载。
- 难度=排队压力（到达率 vs 产能的剪刀差），应随升级阶段性缓和再拉起（锯齿张力）。

**代表案例**：旅行青蛙（极简放置经营）、梦幻家园（经营+三消混合结构）、疯狂餐厅系列、Good Pizza, Great Pizza（竖屏披萨店，lite 标杆）。
