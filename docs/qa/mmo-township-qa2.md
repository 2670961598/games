## 1. 200ms 模拟延迟（可玩性 + 贡献率对照 4+4 局）

**注入方式**：本地 TCP 延迟代理（客户端⇄代理⇄网关，每方向固定 100ms ⇒ 往返 ≈200ms）。代理自证：ping/pong
RTT p50 直连 **1ms** / 经代理 **202ms**。测试房 timeScale 不适用于延迟注入（API 虚拟会话无网络路径，GAMES-48
已证），故对照局全部走**真 WS 会话**。

**对照设计（预算版）**：plain/delay 两臂**并发同场**进同一常驻镇（:4410 影子网关，Lv4、8-11 居民 bot 在镇），
同一采集-倾倒剧本、同资源态世界（天然配对、消除世界演化方差）；每臂 4 局、每局 110s；资源偏好序两臂逐轮轮转
对冲。驱动器与真客户端同款（预测/和解/输入通道逐式复刻）。

| 指标 | plain（RTT 1ms） | delay（RTT 202ms） | 判定 |
|---|---|---|---|
| 完赛局数 | 4/4 | 4/4 | ✅ |
| 倾倒次数 / 贡献值 | 1 次 / **4** | 2 次 / **6** | ✅ 延迟臂不低于直连臂（无负向偏置） |
| 采集完成（gather-done） | 2 | 5 | ✅ 同上 |
| 贡献速率（每臂每分钟） | 0.55 | 0.82 | ✅ 同上（绝对值受 §6 口径限制约束） |
| 走行距离（权威位积分） | 13293px | 11161px | ✅ 同量级移动能力 |
| 输入→快照 ack 回显 p50 / p95 | **51 / 96ms** | **255 / 304ms** | ✅ 精确=RTT+节拍相位（~53ms），无额外服务端时延 |
| 预测-权威和解跳变 max | **1.2px** | **1.2px** | ✅ 两臂一致——200ms 不产生预测漂移 |
| 和解跳变 >32px（client 滑移阈值） | 0 次 | 0 次 | ✅ 零硬修正（32px 滑移通道从未触发） |
| 楔死自救（切向绕行触发） | 4 次/4 局 | 4 次/4 局 | ✅ 两臂同频（驱动器自愈，非游戏缺陷） |

**移动可玩性结论：200ms 往返延迟下可玩。** 机理与实测互证：移动输入为连续量（mx/my），服务端缺包时沿用
lastInput（宽限语义），200ms 只推迟"变向指令生效"一个 RTT，不中断移动——ack 回显 255ms（=RTT+53ms 节拍相位）
而和解修正 max 1.2px、零滑移，即预测轨迹与权威轨迹始终贴合。浏览器面交叉引用 QA1 §6 同款代理实测（CDP 真页
面）：200ms 臂首位移 68ms（纯本地预测，不等服务器）、全程零 >16px 渲染跳变、零方向翻转。证据：`t1-latency.json`
（含每局逐项）、QA1 `cdp-specials.json`。
