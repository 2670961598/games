## 3. 数据模型 v2（修订版）

### 3.1 客户端 localStorage / sessionStorage（唯一访客态存储）

前缀 `games5:`（store.js；隐私模式/配额异常静默降级内存态）。游戏侧 localStorage 用 `games:` 前缀（GAMES-7 §5.2 冻结，宿主禁写）。

| key | 形状（v 冻结） | 写入方/时机 | 定义处 |
|---|---|---|---|
| `games5:visitor` | 字符串 `"v-"+[a-z0-9]{10,}`（读取校验正则；**非 UUID**，v1 ⚰️） | store.js visitorId() 首次生成后长期复用 | dist/src/store.js:28-37 |
| `games5:bag` | `{v:1, remaining:[gameId], cycle:[gameId]}`；不变量：两数组无交集、各自无重复、并集 ⊆ 当前目录 | shuffleBag.js（newBag/reconcile/draw），boot 与每次抽取后 | dist/src/shuffleBag.js:4-11 |
| `games5:stats` | `{v:1, games:{[id]:{count,totalMs,lastPlayed}}, totalMs}`；形状不符整体重置 | stats.js applyEnter/applyDuration | dist/src/stats.js:4-6 |
| `games5:events` | `[{gameId, ms, at}]` 上限 500（超出丢最旧） | main.js recordDuration/flushEvents（15s flush / beacon 送达出队） | dist/src/main.js:10-11,38-41 |
| `games5:wideOk` | `true`（宽屏点击"缩窄继续"后不再提示） | rotate-tip | dist/src/main.js:263-267 |
| `games5:nav`（sessionStorage） | `'1'`（应用内导航标记，播放器返回走历史栈的依据） | route() | dist/src/main.js:157-161 |

### 3.3 game.json 字段仲裁表（三方冲突 → v2 裁定建议）

三方现状：v1 §7（已 ⚰️）｜GAMES-7 §2.1（自称唯一事实源）｜scan-games.js + uploads.js（main 实际执行）。**当前真实生效的是 scan 实读列**——spec 必填字段缺漏不报错、越界值静默收敛，规范与执行脱节（❌G5 开单仲裁，下列"v2 裁定建议"供该单采用）。

| 键 | GAMES-7 §2.1 | scan 实读（生效中） | 上传管线 normalizeMeta | v2 裁定建议 |
|---|---|---|---|---|
| 名称 | `title`（必填 ≤12 中文字） | `name`（缺省=slug） | `name`（≤64） | scan 双读：title 优先、name 兜底；或 spec 改键为 name——**待裁** |
| type | json 字段，24 枚举 | **目录名**（json 内 type 忽略） | query/multipart 传入 → 决定目录名 | 以目录名为准（实况即如此），spec 同步修订 |
| tier | 必填五枚举 relaxed\|simple\|normal\|hard\|master | 任意串 ≤16，缺省 `standard`（**不在五枚举内**） | 同 scan | 五枚举收口、缺省改 normal；存量 standard 映射 normal |
| levels | 必填 int 10-120 | ≥0 缺省 1 | 1-9999 缺省 1 | 平台侧放宽 1-9999（玩家上传无权强制 10+），生产线按 spec |
| slug | json 字段 `^[a-z0-9-]{3,40}$` | **目录名**（json 内无 slug） | slugify ≤64，冲突 -2 | 以目录名为准；生产线格式约束保留在 spec |
| id | 无（type:slug 推导） | json 可覆盖，须全局唯一 | approve 时**删除** json id 强制推导 | 禁用 json id（与上架管线一致） |
| entry | 必填 index.html | 可选，缺省 index.html | 由包内定位决定 | 现状 ✓ |
| description | 无 | 可选 | ≤256 | 现状 ✓（建议 spec 增补） |
| version / specVersion / orientation / controls / avgDurationSec / scoring / assets / typeExtra | spec 必填/可选 | **一律不读** | 不写 | M4 前不强求 scan 校验；建议 scan 透传进清单（feed 可用 avgDurationSec/assets.thumb） |

### 3.4 API 面 v2 快照（main 实况，验收公式见 §5 附）

```
GET  /api/health                          → {ok,uptime,now}
GET  /api/games?page&pageSize≤100&seed&type → {ok,total,page,pageSize,pages,games[]}（max-age=30+ETag；seed=确定性排列）
POST /api/upload                          → 201 {ok,id,state:pending}（zip/单html/multipart；≤2MB；10次/min/IP）
GET  /api/uploads ｜ /api/uploads/<id>     → 待审列表 ｜ 单查（pending/published/rejected/lost）
POST /api/uploads/<id>/approve|reject     → 上架（原子 rename 入 games/）｜ 驳回（reason≤200）
POST /api/stats ｜ /api/play-events       → {events:[{gameId,ms|seconds,at,visitorId}]} 批量；ms 自动换算秒
GET  /api/stats/<visitorId>               → {visitorId,totalSeconds,games:[{gameId,seconds,plays,firstAt,lastAt}]}
GET  /games/*（内部目录 404）｜ GET /*（dist>web，SPA 回退 index.html；未知 /api/* 回 JSON 404）
```
